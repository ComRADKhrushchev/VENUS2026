## 能量泄漏根源调查（2026-10-04，用户两度质疑驱动）

**事实链（全部有档可查）**：
1. 旧 2D 代码 VERLET.f90 内含 **energy_feedback 机制**：逐步测 dH=H−H_last（扣除 Langevin
   功），对全部动量速度重标定把 H 拉回目标（每步上限 0.75T/3T，速度比例限 [0.5,2.0]）；
   其注释自述吸收的正是 "Verlet splitting / missing Pulay force" 的逐步漂移。VENUS.f90
   另有 HTMAX−HTMIN>8 kcal "Energy not conserved, but proceed" 守卫（超上限放行）。
2. 开关史：仓库初始提交（6-23）默认 0；interface_RST_Hubbard 有 "Disable energy feedback
   to isolate force/E0 issues (per user request)" 强制关闭（六月排障期，为看裸漂移——
   3.88 eV 诊断为关闭态测量）；移植 cau_tab 时按用户指示整体移除。
3. 五月 GLO 存档（DT=0.01、解析弱耦合 PES、~30 ps）：逐轨迹 |ΔH| ≤0.157 eV、逐步 dH
   ≤0.06 eV、H 有界 98% 回归——与 feedback 开着或保守积分均相容，开关状态无法唯一裁定。
4. **r8v DT 判定实验**（r6b 表、E1D_0.76、m4、N=50、逐轨迹 |e_fin−e_0|）：DT=0.05 中位
   **5.1 eV** / DT=0.01 中位 **2.2 eV**——DT 敏感证实（~2.3×），且暴露真实逐轨迹漂移为
   **eV 级**（此前"典型 0.27 eV"系跨轨迹 std 推断、共模漂移相消，严重低估；venus 自报
   max 7.9 eV 才是诚实读数）。
5. 差异归因闭合：旧档案小漂移 =（feedback 吸收 或 条件温和：DT 5×小 + Vcp 弱 3-6× +
   时长 3×短）——移植无回归证据；裸漂移两代同源（Verlet 分裂/Pulay 缺失 + bath 子空间）。

**后果与降级**：DT=0.05 生产配置下逐轨迹漂移 eV 级 ≫ 物理能标（入射 0.76 eV）——
此前全部 Edist 精调结论（±0.1-0.2 eV 级）降级为量级参考；通道比/翻转率（布居拓扑）
不受影响依然有效。

（rst 的 1.2 平台反而是待检特征）——"Vcp 压回 rst 量级"路线作废。
