**范围裁定（拟）：**
- S1 **验证分层**（R1）：A 层成员的 check 以**直接注入合成参数**驱动（不经输入
  语法），统计锚（chi-square/分布形状）与解析锚（守恒式/正交性）立即全量；B 层
  成员判据 = 机制（注册/参数验证/调用链/分派正确）+ 守恒式代数（如 GLO 浴的
  阻尼-噪声关系满足涨落耗散形式的解析核对），数值后验 V。
- S2 **Hessian 机制件**（R2）：src/utils/hessian.f90——中心差分，吃力过程指针
  （facade 无关的纯形式，单位契约由调用方负）；check_hessian 用**解析测试力
  函数**（如谐振势/四次势）立即可全量验证（差分 vs 解析 Hessian 收敛阶与精度）。
  频率导出（Hessian→EIGN→w_mode，旧 SELECT:321 代数）在成员装配期作为机制存在，
  空转链下频谱退化 → boltz_init 的"频率全正"验证 loud-stop 属合法姿态。
- S3 **成员参数入语法**：C4.4 留空的中央分发表开始逐行填——每成员的参数键
  （如 incident 的 N_E_REL/T_TRANS/V_WIDTH/THTA_MAX/CHI/N_B/N_AIM，boltzmann 的
  无——频率不走输入，normalmode 的 N_BAR 类合法变体等）按成员到行；行键拦截
  语义不变（表外成员键仍未知键）。
- S4 **表面窗口键集**（C4 移交）：块二增 A_LAT/BOXPAD 二键——仅表面范式（派生
  =1）下必键且合法，分子范式下出现 → loud-stop（与 R3 一致：细分模型归
  container，语法只余晶格常数这类无通用默认的数）；key_tab 增槽宽列（超宽
  loud-stop 点名，不再静默截断）；DIST_SCHEME-vs-n_frag 计数核对 loud-stop 落
  sampler 装配期（输入期 n_frag 未派生——E12 不入体系知识）；specio 补 POSCAR
  速度块跳过首件（读到坐标块尾后正确止步/跳过速度块再验证）。
- S5 **注册走拖入**（E11）：methods/reg_dist*.f90 注册文件（按成员族组织，行数
  不限——wildcard 自动拾取，Makefile 不动）；注册在装配期执行（driver 或
