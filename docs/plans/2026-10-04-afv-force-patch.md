# 子步平均力（AFV）补丁方案 —— 2026-10-04

## 1. 归因回顾（本方案要治的病）

漂移 = 核-电交错积分的**力采样误差**，集中于杂质-浴耦合通道（budget：耦合通道失配
−0.4031 eV @m4 / −0.3917 @m160，其余通道 ≤0.08；`scripts/budget_m4.log`、`budget_m160.log`）。
表现形式：对 msbstp 不敏感（电子侧严格守恒 Tr(ρ̇F)=0）、随耦合增长、近似线性于核步长 dt
（被困网格 `scripts/e6.0_m4.log` −2.957 → `e6.0_dt01_m4.log` −0.706，dt×1/5）。生产同象：
r8v 中位 5.1→2.2 eV（`scripts/tab_experiments.md:166-169`）。

机制：每个核步的功积分用力在**一次 ρ 快照**上的值，而 ρ 在步内大幅相干振荡
（近场接触期浴占据变化 sum|dn| 2.3–5.1，`scripts/e115.3_m4.log` 结尾清点）。修法 = 给核功
配**子步时间平均的 ρ 依赖力**（即旧 VERLET.f90 注释所述 missing Pulay/子步平均力项）。

## 2. 补丁组成

### 2.1 容器侧（已落地，纯被动，零行为变化）

`systems/inactive/cau_peri/cau_peri_tdhf.f90`：

- 新增私有 `rho_dep_force(fr)`：pes 核力的 ρ 依赖部分（杂质对角 + 耦合块 + 均场），
  复用 pes 的缓存约定（前置条件：同 q 先跑过 pes，即 hubbard_eval(.true.)）。
- `cau_peri_prop` 内被动累积：步首 + 每子步末各采样一次（msbstp+1 点梯形），存
  `g_rho_avg`；**不触碰 rhom 的演化**。
- 新增公开 getter：`cau_peri_rho_force_out`（瞬时值）、`cau_peri_g_avg_out`（上一次
  prop 的步平均）。
- 回归证明：旧驱动源码 × 新容器 = `scripts/ref_e6.0_m4.log` **−2.95680**，与补丁前
  `scripts/e6.0_m4.log` 逐位一致。可常驻合入，无回滚风险。

### 2.2 驱动侧（PC-AFV，保留方案）

`scripts/probe_afv.f90`（drift 模式，其余模式不动）：

```
每步：
  kick1 用上一步的校正值 gcorr
  drift → pes(q) 得瞬时 g、V；分解出瞬时 ρ 部 frho
  kick2 预测值 gkick = [g − frho] + ḡ_prev        （静力学部分用当前 q，ρ 部用滞后平均）
  prop(dt) → 本步实际子步平均 ḡ
  校正：gcorr = [g − frho] + ḡ；p −= ½dt·(gcorr − gkick)   （回补第二个半踢）
```

要点：本步的功最终按 **gcorr = 静力学(q) + 本步实测 ρ 平均** 结算，滞后只出现在
预测里、被校正消掉；总冲量 = dt·gcorr，仍是标准 Verlet 形式。

## 4. 已知限制与判读

1. **飞越/快相遇段退化**：PC 在单调快扫掠的相遇段引入反向偏差（V 记账用瞬时 ρ、功用
   平均 ρ 的不一致）。生产 1D 被困率 80–88%，主导分布是被困轨迹（PC 大胜区）；飞越
   亚群补丁后 ~1 eV，仍低于未打补丁被困值与生产 5–8 eV 水平。**不建议按轨迹类型切换**
   （会造成系综内不一致），建议作为已知代价接受或走第 6 节后续。
2. **m160 残余**：dt.05/m160 仅 1.3× 改善——平均消掉了 ρ 采样项，剩余是步内 q 扫掠×
   振荡的协方差项（对 msbstp 不敏感、对 dt 敏感）。配套生产 DT=0.01 建议不变。
3. PC 版可复现：`pc_repro.log` = +0.33098 与 `pc_e6.0_m4.log` 一致。

## 5. 生产接线（VENUS 主程序）

1. 容器补丁照搬（被动累积 + 两个 getter，前置条件 = 现有 force→prop 调用序已满足）。
2. 驱动接线点：力求值后取 `cau_peri_rho_force_out` 分解；prop 后取 `cau_peri_g_avg_out`
   做回补脉冲（½dt·Δg 只进动量，不动坐标/时间）。GWRITE 的 H 自报逻辑不变。
3. 开关：默认关（编译期或输入卡），判收批 A/B 后再定缺省。
4. 判收协议（阈值）：
   - 回归：m4 被困轨迹补丁关闭读数与现值逐位一致；
   - 收益：r6b 表 N=50 批，逐轨迹 |e_fin−e_0| 中位 5.1 eV → **<1 eV**；
   - 不伤物理：翻转率/Edist/角分布与 macc5 基线（`tab_experiments.md:200-204`）在
     统计带内不移动。
