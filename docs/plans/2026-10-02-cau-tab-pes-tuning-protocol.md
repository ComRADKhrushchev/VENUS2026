# cau_tab 表点调优流程（简版，2026-10-02 用户裁定简化）

> 只在当前 cau_tab 容器前提下进行，只对表内数据点做**值级**修改（z 网格、插值律、
> 容器代码均不动）。详细版（Optimization 框架全方法学移植）已被本简版取代，历史见 git。

## 循环

```
改点(旋钮) → 装载自检(探针加载即门) → 本地探针系综(m4, N=100, 同 seed 配对)
→ 读数(散射率/散射翻转率/z_min 分布) → 记入实验日志 → 下一个旋钮
有希望的组合 → 云端 venus 批(Edist/Angdist 对标实验) → m160 判收
```

**旋钮优先级（2026-10-03 用户裁定）：优先修改 E0，Vcp 仅作微调。**

- 探针 = `scripts/ens_cau_tab.exe`（逐轨迹 status/z_min/停留/末态布居；其 Ekin_out 列有
  已知标度缺陷，能量结论一律走 venus 路径）。同 ISEED 配对跑，初条件逐轨迹可对。
- 实验日志 = `scripts/tab_experiments.md`（一行一轮：基表、编辑、读数、结论/下一步）。

## 旋钮（表点编辑词汇，全部 = "窗口内加 C1 钟形"或"远场平滑归零"）

| 旋钮 | 操作 | 物理语义 |
|---|---|---|
| K1 | E0/top 位垒窗 [1.55,2.10] 下压 | 顶位垒高度——位垒外坡弹性反弹 = 未翻转旁路 |
| K2 | E0/全位点阱窗 [1.7,3.1] 上抬 | 阱深——被困率与反弹速度 |
| K3 | E0/全位点远场 [5.3,6.25] 归零（ramp0）+ h/U 远场 [3.9,6.25] 保位（hold） | 发射点无力条件（见下）|
| K4 | E0/内壁窗 (<1.5) | 内壁硬度 |
| K5 | Vcp 近场缩放 | 杂化强度（翻转速率）|
| K6 | J 近场平移 | 交换压制深度 |
| K7 | h 近场平移 | 能级对准 |

合法性门（每轮必过，违反即废轮）：装载自检过；**发射点无力条件**——发射高度 z=6 处**所有**
通道梯度≈0（不止 E0：current 谱系 h/U 远场持续下降的斜率 × 双占据杂质产生 ~+3.6 eV/Å 向上
力，基线中被 E0 上翘斜坡（−4 eV/Å 向内）掩盖；一旦 E0 归零即成发射反射源，轨迹在 z≈5.86
被弹回、从不入射——2026-10-02 第 1 轮实测确诊，修法 = h/U 用 hold 从 3.9 Å 锁定到窗口起点
值，物理依据 4 Å 外孤立原子通道无 z 依赖）；E0(6)→0、Vcp→0、J→1.24；改后表 FD 对拍无振铃
（沿用 check_cau_tab 口径抽查）。同轮只动一个谱系的一组假设。

编辑器 = `scripts/tab_edit.py`（值级修改，z 网格不动；操作：bump 钟形 / ramp0 远场归零 /
flat 末值趋近 / hold 起点保位；输出表顶部 '# edit:' 注记行随装载回显进运行记录）。

## 目标读数（实验锚点）

- **通道比**：1D 入射散射轨迹翻转率 → ≈100%（实验无 1D 回束）；3P 入射反向翻转 =0。
- **Edist**（venus 路径）：1D 出射峰位 0.28/0.36 eV（0.63/0.76 入射，Table 4.5 A 级）；
  即 ~55% 能损 + 仍有散射通量。
- Angdist 形状参考（数字化 B/C 级）。
