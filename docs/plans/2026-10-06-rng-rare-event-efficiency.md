## 0. 问题与结论摘要

用户问题：对于期望观察到低几率事件（稀有反应通道）的计算，特定的随机流机制能否
提高计算效率？

结论（详见 §2/§3）：**能，但效率来源要分清三层**——

1. **换更高质量的发生器本身不降所需轨迹数**（误差是统计性的 1/√N，不受发生器
   质量限制；现行 Knuth MCG + 洗牌表对当前批规模足够）；
2. **抽样定律层**（分层/重要性抽样/低差异序列）才是降低"每条轨迹信息成本"的
   主力，本树全部抽样定律均为可逆 CDF，权重比可精确解析——先天条件有利；
3. **流拓扑层**（每轨迹独立子流）不降方差，但解锁轨迹级并行（程序当前串行）与
   批可扩展性——低几率事件最朴素的墙钟效率来源。

效率标尺（换算式，非文件读数）：纯 MC 观察概率 P 的通道、相对误差 ε，所需轨迹数
N ≈ 1/(P·ε²)；P=10⁻⁴、ε=10% 时 N ≈ 10⁶（其中约 100 条反应轨迹）。当前统计相
（driver.f90:253-272）正是这种朴素等权估计器。

## 1. 审计事实（随机数机制现状；出处 = 当日直读文件行号）

### 1.1 发生器与变换（src/utils/rng.f90）

- Knuth 乘法同余 X ← A·X (mod 2⁶⁴)，A = 6364136223846793005，C = 0，以 8 个
  base-256 数字逐位卷积实现（rng.f90:27-58；常数注释 rng.f90:33-34）。旧 VENUS
  为 32 位机器做多精度乘法的遗传承载。
- 出口净化：Bays–Durham 洗牌表 100 项（rng.f90:21），抽表尾、按表内容选指针
  回填（rng.f90:105-111）。
- 播种：十进制种子（0 ≤ i_seed ≤ 2³¹-1，rng.f90:65）→ base-256 展开 → 逐位
  加倍 → +1（保证奇种子）→ 洗牌表填两遍共 200 次预热丢弃（rng.f90:64-99）。
- 变换 API：rng_u（均匀 [0,1)）；rng_gauss（Box-Muller 极坐标形式，缓存半个
  对——**每对消费的均匀数个数可变**，rng.f90:117-134）；rng_gamma（order 个
  均匀数连乘取 −log，rng.f90:140-149）。
- 周期（推断，非文件直读）：A ≡ 5 (mod 8)（6364136223846793005 mod 8 = 5），
  mod-2⁶⁴ 乘法同余周期 = 2⁶²（标准性质）。当前批规模（数百至数千轨迹）远未触及；
  仅超大批 + 超稀有事立项时才需评估。

### 1.2 流拓扑

- **全程序唯一一条全局顺序流**：装配期 rng_init(i_seed(1)) 调用一次
  （driver.f90:102）；ISEED 标量规则 = 只用语 1（input.f90:716-718；i_seed 共
  8 字声明见 control.f90:17，其余字不参与）。
- n_traj 条轨迹在串行循环里依次消费同一条流（driver.f90:180-231）；程序无
  MPI/OpenMP（2026-10-06 src 树 grep 零命中）。
- 可复现锚点：同种子 → 同均匀序列（rng.f90 头注 6-9 行明言）；五 case
  same-ISEED 逐字节一致是现行回归口径（README.md:39-40）。

- 通道计数等权 MC：cnt_outc → 计数/打印（driver.f90:253-272）；直方图

### 1.5 结构性后果（审计发现的约束，任何更改方向的共同前提）

1. 每轨迹均匀数消费数变长（Andersen 每步判定 + Box-Muller 缓存奇偶 + 三处
   拒绝法循环）→ **轨迹 k 的随机数依赖全部前史含前序轨迹的动力学长度**。
2. 推论一：n_traj 扩批改变后续**所有**轨迹（无批可扩展性——"多跑 1000 条续在
   后面"在现行单流下不成立）。
3. 推论二：任何并行化必然改变轨迹集合 → 回归锚点（§1.2）需重立法。
4. 推论三：QMC/固定抽取数类方案需先重构消费面（见 D4 前置）。

## 2. 效率问题定式

- 观察概率 P 的通道至相对误差 ε：N ≈ 1/(P·ε²)（二项方差标准换算式）。
- 当前代码即朴素估计器（§1.4），轨迹是完整 MD 积分（贵），浪费集中在大量
  "空"轨迹。
- 关键区分：**统计方差由样本放在哪里决定（抽样定律），不由流的品质决定**；
  流拓扑决定的是吞吐（并行/批扩展）与配对能力（CRN）。

## 3. 更改方向（候选，按建议处理序；每条含机制/增益/改动面/前置/风险）

### D1 每轨迹独立子流（counter-based 发生器或 MCG 跳前）

- 机制：Philox/Threefry 类 counter-based，key = (主种子, 轨迹号)；或对现行
  MCG 做模幂跳前（A^k mod 2⁶⁴ 可解析预进）。
- 增益：**轨迹级并行的前提**（程序当前串行；低几率事件最便宜的墙钟效率来源）；
  批可扩展（消除 §1.5-2）；D5 的载体。
- 改动面：rng.f90（流标识参数化）+ driver.f90 轨迹环头（每轨迹建流）。
- 前置/风险：①**禁用连号小种子派生**——MCG 顺序种子产生相关前缀，现行
  rng_init 的加倍+预热只缓解不保证独立；派生必须 counter-based 或强哈希混合。
  ②改变全部轨迹 → 回归锚点重立法（§5 R1）。
- 不降方差（如实标注）：增益全部在吞吐与拓扑性质。

### D2 碰撞盘 b² 分层/系统抽样

- 机制：b² 空间分 N 个等概率层、每层抽一点（系统式 (i−½)/N 或随机分层），
  替代独立同分布的 b_max·√u。
- 增益：对光滑 P(b) 收敛从 N^(−1/2) 推近 N^(−1)（方法学标准结论，推断）。
- 改动面：beam_laws.f90:243 一处 + 统计相误差报告。
- 前置/风险：轨迹间不再独立 → **二项误差棒失效**，必须改"分层批重复"口径
  （多批随机分层，批间估计误差）；输出面（results.txt/直方图归一）随之审。

### D3 重要性抽样 + 重加权（b / E_rel / 初始振动量子数 n）

- 机制：从偏向反应区的提议密度 g 抽样，每轨迹带精确权重 f/g 进统计；σ_r =
  π·b_max²·mean(w·1[反应]) 无偏。
- 增益：深层稀有通道（P ≲ 10⁻⁴）数量级削减轨迹数——前提是偏置密度选得好
  （侦察批/廉价代理势可提供）。
- 先天有利：本树全部抽样定律是**可逆 CDF**（§1.3 表），f/g 全部解析可算。
- 改动面：抽样成员提议密度（beam_laws 抽样层；samp_boltzmann.f90:238 几何
  分布一处换偏置定律 + 玻尔兹曼权重比）+ **权重管道**：trajectories.txt 加权
  列、driver.f90:253-272 等权计数改加权和、直方图归一改加权。
- 前置/风险：无偏性依赖提议密度比精确已知（成立）；提议密度选差时权重方差
  爆炸（诊断量：有效样本数）。

### D4 随机化拟蒙特卡洛（scrambled Sobol 低差异流）

- 机制：均匀流换低差异序列（随机化保误差棒）；低维（初条件空间 ~5-15 维）
  光滑被积函数误差 ~O(N⁻¹·logᵏN)。
- 增益：对二值反应指示函数（不连续）增益缩水但 RQMC 通常仍稳赢 iid MC
  （方法学标准结论，推断）。
- **前置重构**（最大代价点）：每轨迹抽取数必须固定——§1.3 全部变长消费点
  （Andersen 判定、三处拒绝循环、Box-Muller 缓存）改为"每轨迹预抽定长向量 +
  循环内消费 + 上限"。
- 风险：重构面大，建议 D1-D3 之后才立项。

### D5 公共随机数/对偶配对（变体比较）

- 机制：同初条件流跑两个哈密顿量（同位素/势面变体），差值估计量方差大降；
  对偶变体（u ↔ 1−u）对单调响应有增益（QCT 响应非单调，增益有限，如实标注）。
- 载体：D1（每轨迹独立流）先行。
- 改动面：driver 批层配对调度 + 结果表成对输出。

### D6 分裂法/加权系综（最深层稀有事件）

- 机制：轨迹进入进展坐标区域分裂、返回时淘汰，committor 加权估计。
- 适用：P ≲ 10⁻⁶ 且有好进展坐标（如键长——容器判据槽已跟踪的量）。
- 定性：估计器级改动（非流机制），架构级工程；仅当 D1-D3 不足时立项。

## 4. 明确不做（non-goals）

- **单纯换"更好"的发生器**（MT19937/xoshiro 等）以图稀有事件效率——不降
  所需轨迹数，零收益；现行 MCG 的 2⁶² 周期（推断，§1.1）对可见批规模无约束。
- **连号种子派生子流**（i_seed + k）——MCG 小种子相关前缀病理（§D1 风险①）。
