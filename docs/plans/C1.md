**Goal:** the three L5 instrument files go from skeleton (pseudocode bodies) to verified
real implementations, each with a minimal verification input + acceptance criteria
DEFINED FIRST (per §9), executed and recorded. C1 is the first Phase-C step — the
concretization discipline (per-file provenance-faithful porting + the audit's
"do-not-carry-over" list) starts here.

**Design decisions (proposed, confirm with the plan):**
- D1 **Bit-faithful rng port**: the RAND0/RAND1/RANDST algorithms and their constants
  are carried over verbatim (same seed -> same sequence as the old library). Ground: the
  V-phase "same-ISEED reproducibility" criterion and ad-hoc same-quantity cross-checks
  against the old program both presuppose an unchanged stream.
- D2 **gasdev source switch stands** (the P-C1 ruling carried into the new tree): the
  internal uniform source becomes rng_u (the single stream, T5) — the sequence therefore
  DIFFERS from the old library's gasdev (which drew from an independent RANDOM_NUMBER
  stream). Intentional, legislated, recorded; Box-Muller + cache preserved.
- D3 **Verification harness location**: scripts/check_rng.f90 / check_linalg.f90 /
  check_geometry.f90 — standalone programs compiled by hand against the built module
  (`gfortran scripts/check_rng.f90 src/utils/rng.f90 -o build/check_rng.exe`; the
  Makefile's "never changes again" principle holds — no check target). The V phase
  assembles the formal case set from these; the C-phase records live in this file's
  step notes.
- D4 **EIGN port scope**: eig_sym(a, d) takes an arbitrary-n symmetric matrix (the
  skeleton signature governs); the EIGN.f algorithm (Jacobi orQL as found) ports with
  its convergence constants verbatim.

  dir as -module:DIR (colon) — the space form is silently ignored and .mod files land
  in src/, poisoning later gfortran runs; the Makefile now uses the colon form on
  Windows (MODDIR), per-compiler build trees keep the two compilers fully isolated

**Acceptance:**
1. Three instrument files real (no pseudocode bodies left in rng/linalg/geometry);
   signatures untouched (drift ban);
2. Each check program's criteria pass with the numeric evidence recorded here;
3. Single-stream statute holds (the T5 grep);
4. Dual-compiler build green;
5. No system knowledge entered the instruments (the E12 reverse posture: these are
   generic algorithm stock).

**Risks:**
- RAND0-family porting drift (F77 idiom -> free form): mitigated by carrying the
  arithmetic verbatim and checking the first-draw sequence against the old library's
  output for one seed (an ad-hoc same-quantity anchor, not a baseline);
- the Brecht-Sanders gfortran 15.2 quirks (compressed .mod) interacting with the
  hand-compiled check programs — compiled with the same -J build dir conventions;
- EIGN.f may arrive dimension-limited or with scratch-array conventions — adapted to
  the frozen signature (allocatables local), the algorithm constants verbatim.
