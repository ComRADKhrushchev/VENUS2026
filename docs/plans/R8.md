## 目标与总则

程序"没有问题"的最终外部判据 = **文献报告体系复现**:每个基准体系在新程序上的
计算结果与文献参考值点在**事先声明的容差内**一致。此前 V 相的 golden 对照只证明
"新程序 = 旧程序";R8 证明"程序 = 文献报告的物理"。

四步骨架(用户 2026-09-17 设定):①拉取文献数据、确定验证指标 → ②指标对应到
具体计算任务与观测量 → ③构建体系对应的物理系统容器 → ④拟定输入、开始计算和统计。
每个体系都完整走一遍四步;四步内的横切纪律:

- **判据先行**:参考值表与容差先写(步骤一),对照后跑(步骤四)——五 case README
  §3/§4 体例沿用到 R8 case。
- **物理常数姿态**:文献势能参数/光谱常数逐字入库并标出处(表号/页码),解析复算
  不复推、不换算重导。
- **回归保护**:每批落地 = 双编译器重建 + 五 case 逐字节 + 相关 check_* 重跑 +
  T4/T5 grep 复验(EXTENDING.md 演练清单)。
- **每体系四件套**:物理系统容器文件夹(systems/<sys>/)+ case 文件夹(cases/case_r8_<sys>/,
  判据先行 README)+ 判据程序(scripts/check_<sys>.f90)+ results.txt 入库。
- **停驶纪律**:R8 期间发现的程序缺陷单独立案决定修复,R8 阶段内不顺手改共享代码。

## 步骤一(R8-A):拉取文献数据,确定验证指标

产出:`docs/benchmarks/<sys>_anchors.md`——每体系一份参考值表(指标|文献值|出处
表号/图号|数据形态|容差类),入库后才进步骤二。

1. **取数**:
   - R8-1:Aguado 1994 的 σ_R(E_T, j=0/1/2) 数值表与 k(T) 表优先(数值表精度高);
     DCS 若仅以图载,读图取值并标注"读图近似";LEPS 参数(Takayanagi-Sato 1988
     表)逐字抄录入参数文件模板。
   - R8-5:Tully 1990 三模型(single/dual avoided crossing,extended coupling
     with reflection)的 H11/H12/H22 解析式与参数逐字入库;跃迁/透射概率曲线
     读图取值;**LZ 解析极限**单列(可复算,容差最紧)。
   - R8-3:Zhou & Jiang 2019 的振子/摩擦参数与 T_s 序列;sticking 曲线读图。
   - R8-4:η 区间/倍数结论行(方法论级,无数值表对表要求)。
2. **容差三分法定则**(参考值表每行标注):
   - T-解析:解析可复算量(LZ 极限、GLO 解析式)——紧容差(数值积分误差+MC 统计);
   - T-数值表:文献数值表参考值——文献自身有效位数 ∪ 3σ_MC,取宽;
   - T-读图:图载参考值——显式放宽(读图误差 ~线宽量级),宽度写入参考值表,不事后调。
3. **R8-L 并行**:三篇基准文献入 EndNote(用户侧,EndNote 关闭时执行)。

## 步骤二(R8-B):指标 → 计算任务与观测量

产出:映射表(每指标一行:文献参考值|计算任务|初条件方案|观测量提取|统计口径|容差|
**缺口**)附于各参考值表;缺口集中决定后进步骤三。

- **R8-1(F+H2)**:
  - 任务:F(v=0, j=0/1/2) + H2 单碰撞能 QCT;E_T 网格覆盖文献横轴。
  - 初条件:**EBK 定 (n,J) 态**(dist_ebk,Morse 光谱常数通道)+ incident 通道
    (E_REL 定值,b² 均匀 [0, b_max²]);**b_max 先扫描定反应窗口**(收敛判据:
    边缘环带零反应增量)。
  - 观测:终态分类(物理系统容器 classify:HF 通道=反应)→ σ_R = π·b_max²·N_R/N;
    DCS = 散射角直方图(hist_thta 类);k(T) = 激发函数对 Maxwell-Boltzmann
    权重积分(后处理脚本,梯形/对 E_T 网格)。
  - 缺口预判:EBK 的 Morse 常数是否适配 H2@该 LEPS 键参数(步骤二核实,必要时
    常数走物理系统容器参数文件)。
- **R8-5(Tully)**:
  - 任务:一维两态散射,动量 p 网格;每 p 点 N 条轨迹。
  - 嵌入约定(决定点):natom=1,dof=3,势仅依赖 q1=x,y/z 零力零初速——判据程序
    锁死该约定。
  - 初条件:定动量 p 沿 x;活性面初占据(振幅初值 = 物理系统容器/方法包成员 init 职责)。
  - 观测:终态面占据统计(occ 通道,occ_get)→ P_跃迁/P_透射 vs p;n_hop 辅助。
  - 缺口(已确认):**首个真 MQC 方法包**(FSSH 形 prop/match)+ level-2 组件
    计划位落地(amp_*/fssh_g_ij/hop_decide/momentum_rescale,EXTENDING.md §3
    在册计划位,全库现无实现);LZ 极限对照要求 prop 的振幅 ODE 与解析式一致
    (判据程序先锁)。
- **R8-3(GLO)**:
  - 任务:解析振子+摩擦(随机律,rng 单流物理系统容器内消费);T_s 网格。
  - 初条件:surface_oscillator(T_s 相关初占据)+ 入射通道(glo_target 配套)。
  - 观测:classify stuck/scattered → S(T_s) 曲线;与解析预言(T-解析容差)对照。
- **R8-4(H2O/Ni(111))**:结论性对照三行(η 区间/top 反常方向/θ 倍数量级),
  不做逐点数值表对表;PES 材料来源(库 id=318)在步骤二核实——若需外部数据
  文件,加载面走参数文件通道,单独立项决定。

## 步骤四(R8-D):拟定输入、开始计算和统计

1. **case 材料**:cases/case_r8_<sys>/(README 判据先行——§3 预期判据=步骤一参考值表
   原文,§4 对照跑后回填;input_qct.txt;物理系统容器参数文件)。
2. **输入要点**:ISEED 定死(同 ISEED 两次运行逐字节 = A2 确定性判据沿用);
   INTEGRATOR/DT 逐体系声明(verlet 基线,radau 备能量品质核验);R8-5 加
   ELEC_METHOD = fssh、N_SURF = 2。
3. **ntraj 定则**(统计纪律,写入参考值表):概率类观测量按二项置信区间声明——
   σ_P = sqrt(P(1-P)/N);默认 N ≥ 1e4/点(P=0.5 处 σ ≤ 0.5%);昂贵点可降 N,
   容差同步显式放宽。曲线类结论(趋势/交点)以"点值全部落入各自 CI"为绿。
4. **批跑与统计**:逐网格点批跑 → 后处理脚本产出对照表(参考值|计算|Δ|容差|判定)
   → 全绿后 results.txt + README §4 入库。
5. **Notion 对账**:每体系端到端绿后,按 propose → 用户确认 → apply 流程勾选
   对应 R8 行(证据指针 = 本文件验收区 + case README §4)。
