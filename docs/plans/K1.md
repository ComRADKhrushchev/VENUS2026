**本文术语约定**（首用即注）：
- **原子清单**（roster）：体系构成表——每原子的元素符号、质量、片段归属，及
  片段几何与晶胞参数。承载文件 config_roster.f90。
- **物理态变量**（规范称"物自体"）：不可再约化的物理变量——坐标 Q、动量 P、
  电子态 s、力 F。承载文件 state.f90。
- **固化操作**（规范 §3.1）：把体系规定从代码搬进数据——功能有界的族
  （核传播子、电子方法等）预先写好封闭选择，经输入数据选择。
- **注册族成员**：可通过"新增文件 + 一行注册"接入的可换实现体
  （pes_* 势成员、dist_* 初态分布成员）。**成员 = 代码 + 自带数据**。

**目标：** 重新构建四个 L1 模块的最小声明。表象区的组织遵循规范 §3.2 的
分解：**①控制流必须变量**（独立模块 control.f90）＋ **②可观测量** ＋
**③接口固化操作导出的四类输入规定**（核传播子 / 电子空间-电子传播子 /
反应物 / 事件），后者以 type 封装，尚不明确的具体变量**留白**（注释占位，
不声明死）。

**交付物：**
1. `src/consts.f90` / `src/state.f90` / `src/control.f90` / `src/config.f90`
2. §2 旧库对照索引（C 阶段参考）
3. 提交 `K1: 全局变量最小集（state/config/control/consts，按规范推理重组）`

**设计决策：**

D1 **state 用派生类型**，driver（主控程序）持有、参数传递——与门面签名
(Q,P,s)→(F,E) 参数式一致。
D2 **派生量与积分器工作区不入 state**（速度=P/质量等归传播子内部）。
D3 **质量归原子清单**（config_roster.f90，K2 建骨架）。
D4 **表象区组织自规范推演**（用户裁决 2026-09-06）：控制流 / 可观测量 /
固化导出规定（type 封装）；不取任意分区。**控制流单独成模块 control.f90**
（抉择理由：规范 §2.2 控制核不含物理知识——其输入变量（任务、轨迹数、
种子、标题）与物理规定分置，主控程序只 use control，物理模块不引用它）。
D5 **type 封装 + 留白**：每类规定一个派生类型；已明确变量如实声明，未明确
者以注释留白（写明留给谁、何时定），不做假声明。
D6 **命名规范**：可辨识短缩写、小写下划线分段、每段 1-6 字符、惯用单字母
优先；每行中文注释（含义+单位）。
D7 **最小集原则**：只保留支撑框架的最少变量；缺项在 C 阶段由消费者按需
引入；死变量（旧库无消费者者）永不进入。

### 1.2 src/state.f90（物理态变量容器，同 v4）

```fortran
module state
  implicit none
  private
  public :: elec_t, state_t, state_create, state_destroy
  type :: elec_t          ! 电子态 s（运行时）：绝热 = 退化点（单面）
     integer :: n_surf = 1   ! 势能面数
     integer :: i_surf = 1   ! 当前面索引
  end type
  type :: state_t
     integer :: natoms = 0   ! 原子数（运行时由原子清单确定）
     integer :: ndof   = 0   ! 自由度数 = 3*natoms
     real(8), allocatable :: q(:) ! 坐标 [Å]
     real(8), allocatable :: p(:) ! 动量 [amu·Å/(10 fs)]
     real(8), allocatable :: f(:) ! 力 [内部能量/Å]
     type(elec_t) :: s
     real(8) :: t = 0.0d0     ! 轨迹时间 [10 fs]（主控程序持有）
  end type
end module
```

### 1.4 src/config.f90（表象层：可观测量 + 固化导出规定，type 封装）

```fortran
module config
  implicit none
  private
  public :: propagator_t, electronic_t, reactants_t, event_t, observables_t
  public :: propagator, electronic, reactants, event, observables

  ! ===== 固化操作导出的输入规定（规范 §3.1-3.2）=====

  ! 核传播子（规范 §3.2-1：功能有界，封闭族固化）
  type :: propagator_t
     integer :: id    = 1     ! 积分器编号（verlet/symple/radau 封闭三成员）
     integer :: order = 0     ! 阶数/变体参数
     real(8) :: dt    = 0.01d0 ! 步长 [10 fs]
     ! 留白：自适应步长界 dt_min/dt_max（RADAU 具体化时引入，C6）
  end type

  ! 电子层面（规范 §3.2-2：两独立轴——H 表示能力级 × 电子传播律）
  type :: electronic_t
     integer :: method = 1       ! 电子传播律（1=绝热退化点；非绝热预留）
     integer :: n_surf  = 1      ! H 表示能力级（单面；多面/耦合留待非绝热）
     character(len=32) :: pes_main = ''  ! 主势成员名（H 场提供方，接口 A）
     ! 留白：加性力成员表（GLO 弹簧/朗之万 ghost/LDFA——C2 随门面引入）；
     !       介电/外场等能力级扩展
  end type

  ! 反应物规定（规范 §3.2-3：构型规定 + 初态统计分布，皆输入数据）
  type :: reactants_t
     integer :: n_frag = 1           ! 片段数
     integer :: surface_model = 0    ! 构型范式（0=气相；1/2=表面两范式）
     integer :: dist_scheme(2) = 0   ! 各片段抽样方案（指向 dist_* 成员）
     real(8) :: e_rel  = 0.0d0       ! 碰撞能（相对运动分布）[kcal/mol]
     real(8) :: b_max  = 0.0d0       ! 最大碰撞参数 [Å]
     real(8) :: r_sep  = 0.0d0       ! 初始间距 [Å]
     ! 构型细节（名册/几何/晶胞）由 config_roster 承载（K2 骨架）；
     ! 留白：取向规定、各片段分布参数——由 dist_* 成员自带（成员=代码+数据）
  end type

  ! 事件规定（规范 §3.2-3：终止谓词 + 结局分类，数据非代码）
  type :: event_t
     character(len=256)  :: term_expr   = '' ! 终止谓词表达式（C3 接入）
     character(len=1024) :: outcome_tbl = '' ! 结局分类表（C7 接入）
     ! 留白：事件类别扩展（约束窗/多事件耦合——谓词文法定形时补）
  end type

  ! ===== 可观测量（通用能量项与记录设置）=====
  type :: observables_t
     integer :: rec_level = 2          ! 记录详细度（预设列组）
     character(len=256) :: obs_list = '' ! 观测列名单（C4 记录器列注册）
     logical :: e_kin = .true.         ! 动能 T（通用能量项）
     logical :: e_pot = .true.         ! 势能 V（通用能量项）
     logical :: e_tot = .true.         ! 总能 H（通用能量项）
     ! 留白：更多观测量随记录器列注册扩展（角动量、局域量等，C4/C8）
  end type

  type(propagator_t) :: propagator
  type(electronic_t) :: electronic
  type(reactants_t)  :: reactants
  type(event_t)      :: event
  type(observables_t) :: observables
end module
```
