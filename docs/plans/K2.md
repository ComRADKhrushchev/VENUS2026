每例程三件套：输入/输出签名 + 中文伪代码 + 参考出处注释（旧库 文件:行）。
不写实现；K1 四模块不新增全局变量（反向核对）。

**延后清单（C 阶段按需引入，不在本阶段）**：
- pes_* 力成员族全部 6 文件（reference/emt_nn/rst/glo_spring/ghost_langevin/
  ldfa）→ C2 随门面具体化逐个引入；
- dist_* 其余 9 个成员（surface_oscillator/rotation/j/barrier_excitation/
  thermostat/glo_target/thermalize/normalmode/qmmicro）→ C5；

**术语**（同 K1）：原子清单（roster）；注册族成员（成员=代码+自带数据）。

**交付物：**
1. §1 文件树全部 19 文件（src/ 终位；analysis/ 子目录）
2. 每文件：模块头（层归属+职责+参考清单）+ 例程签名 + 伪代码 + 出处
3. 提交（4 批）+ K2 总审查 + 审核门材料

**设计决策：**

E1 **占位三件套规范**：①例程 interface（哑元：名/类型/意图/单位注释）；
②伪代码体（中文步骤，对齐旧库出处，禁止可执行实现）；③出处注释
（`! 参考: 旧文件:行`）。
E2 **成员自带参数**：dist 示例骨架声明参数派生类型（字段留白允许，
注释"C 阶段定形"）。
E3 **瘦身裁决（用户 2026-09-06）**：pes_* 延后 C2；dist_* 仅 3 个示例
（boltzmann/ebk/incident——覆盖分布成员原型与入射通道两类形态），
且**不含 sample 例程**（仅 init + params 骨架）；sampler.f90 框架保留
（B′ 框架槽位，samp_run 伪代码标注"分布成员表 C5 填充"）。
E4 **K1 反向核对**：骨架只 use K1 四模块；缺全局变量 = 骨架漂移，
记清单回审核门。
E5 **不动 Makefile**：K3 统一填 SRC + 桩主程序 + 整树编译。
E6 **批次执行**：4 批（L5+roster / 封闭族+门面 / dist 示例 / L4+L0+input），
每批一次实现派遣+快速审查，K2 末一次总审查。
E7 **driver 骨架**：program 占位，三相位伪代码（装配→演化→统计），
演化环内只调 facade/propagator/recorder/predicate（规范 §2.5 相位限制）。
E8 **目录组织（用户裁决 2026-09-07，三次修订定案）**：目录名去层标号、
改正式命名；根只留入口两件 driver.f90/input.f90；变量与规定五件入 globals/；
封闭族（predicate/propagator）入 dynamics/；注册族成员目录 interface_ 前缀
两家——interface_electronic/（规范 §3.2-2 电子层面两轴同家：甲类 pes_* H 场
提供方 C2 落此 + 乙类 elec_* 电子传播律，elec_adiabatic 先行、IESH 将来同住；
轴分离由模块独立 + reg_pes/reg_elec 双注册表 + 能力级协商保证）与
interface_distributions/（B′ 初态分布）。L0-L5 层概念保留于文档层映射表，
不带进目录名。
E9 **多面 PES 接口升级（用户裁决 2026-09-07：立即升级 + 双签名并存 +
一包全升；四场景思维实验的裁决产物）**：甲类双签名并存——pes_diab_i
（透热 H_ij+∇H_ij，IESH 模型哈密顿量天然此形；绝热视图经 utils/linalg
对角化现算）/ pes_adiab_i（绝热各面 V_i/力 + 当前面导数耦合行——仅当前面
O(ndof·n_surf)，跃迁后随新面重算），单面标量签名 pes_proc_i 原样保留
（六个 C2 单面成员零触及，加性语义不动；多面主势不做加性叠加，加性标量
成员只进核力通道）。乙类签名扩 dt（elec_proc_i(s, f, dt)——跃迁概率
g_ij(dt) 依赖步长；绝热成员忽略）。elec_t 扩电子振幅 amp(:)（|c_i|²=布居）
与跃迁计数 n_hop（非绝热观测量；绝热退化点=单元素恒 1——良定义保持，
state_create 加可选 n_surf）。能力级协商数据化 triad_tbl 四行（现行
单面绝热 + 多面 tsh/iesh 预放行——乙类注册槽空由 facade_init loud-stop
兜底，双闸门；**radau 列在多面行恒假**——自适应序列"一步"无良定义）。
涉及 state.f90（真实现）与 force_facade.f90（接口/表真代码 + 例程伪代码）；
elec_adiabatic/propagator/driver 关联注释同步；退化等价验证（n_surf=1
与标量通道 bit 级一致，N1.1 同款判据）随 C2 pes 成员落地时执行。
E10 **工作区模式修订（用户裁决 2026-09-07：独立模块 elec_ws + 完全归一单签名 +
注释立法字段名不动——E9 的公理化修正，"表象构件不具有物自体地位"）**：
三公理立法——A 接口不变性（abstract interface 对体系与表象双不变：签名只传
容器 ws_t，不传 h_ij/d_ij 等形态数组；E9 的 pes_diab_i/pes_adiab_i 双签名与
i_surf 入参撤销——表象与电子态知识不进甲类签名）；B 黑箱性（甲+乙类合为一
个 system black box——箱外只见 (Q,P,s[,dt])→(F,E)，facade_force 签名零变化；
ws 为门面局部变量，箱内声明箱内消亡）；C 物自体原则（H_ij/d_ij/V_i 等表象
构件不进 state_t、不出箱外、生命周期一步）。落地件：新增 facade/elec_ws.f90
（零依赖契约模块——ws_t 容器 + r_empty/r_scalar/r_diab/r_adiab 填充模式
标记；i_surf 经请求字段 ws%i_want 传达）；force_facade 甲类签名完全归一
pes_proc_i(q, mass, ws)（intent(inout)——门面预写请求字段、成员填交付字段）、
注册单入口 facade_reg_pes(name, proc[, repr])（缺省 r_scalar——六单面成员
注册行零触及；E9 双注册例程 facade_reg_pes_diab/adiab 删除）；乙类
elec_proc_i(s, f, dt, ws)（ws 只读消费，成员不支持的 repr → loud-stop）；
triad_tbl pes_kind 列语义改 ws 填充模式（四行表数据不变）；facade_force
伪代码统一为 ws 填充模式路径（多面力核构成降为 4' 分支注记）。state.f90
elec_t 注释立法：amp(:) 只承诺复数组，索引语义（面表象 i=面号/单电子表象
i=电子×态张量积展平/组态表象 i=组态编号）由乙类方法成员定义——字段名不动。
elec_adiabatic 适配器注释扩"忽略 dt 与 ws"。退化等价验证判据随 E9 沿用
（C2 执行）。
