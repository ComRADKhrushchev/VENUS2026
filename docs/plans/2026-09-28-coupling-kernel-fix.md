# 2026-09-28 耦合梯度装配缺陷修复（cau 容器家族，用户举报确诊）

## 动因与诊断

用户对 E3P 条件 260 kcal 级能量漂移提出质疑：原始 VENUS-TDHF（MAIN/3/C@Au_TDHF/2D，
TDHF_U.f90）漂移远小且满足功-能恒等式；怀疑程序内能量与力不匹配，指向梯度矩阵装配。

对照审计确诊：原版 Calc_force 装配**完整对称梯度矩阵**（Grad(ii,j) = Grad(j,ii) =
dR_dVk·√(w/2)，含 (bath,imp) 伴偶元）后取全迹 −Tr(ρ·Grad)；移植模板的手写核折叠
只累加了 Re ρ(imp,bath)·√(w/2)·dVcp **一次**——耦合力的对称伴偶项缺失，**耦合力
恰好减半**，而能量侧 e_elec 用全迹（正确）。这是严格的力 ≠ −∂V/∂q 失配，性质与
用户怀疑完全一致。

**盲区成因**（为什么判据没抓住）：种子的 ρ 是对角的，一步 Magnus 后非对角元为
纯虚（dρ/dt = −i[F,ρ]，实对称 F 下从实对角出发首阶纯虚）；缺失项恰好只读
Re ρ(imp,bath)——旧 (h) FD 腿在对角 ρ 背景下两种装配都过。

## 修复

四容器同修（模板级缺陷）：cau_peri / cau_emt2 / cau_rst / cau_emtnn 的
`<mod>_tdhf.f90` 耦合核块补上两个对称伴偶项（显式 (bath,imp) 项，镜像原版全迹
约定，对非厄米数值 ρ 亦正确）。
