**目标：** 主体程序第四块成真——**driver 三相位成真**（装配 → 演化 → 统计），
把 C4（数据链/输入/记录）、C5（采样）、C6（传播+最小力径）接成**可运行的
整程序**；补上分发行→成员参数的装配缝；以**测试容器**（systems/ 拖入的
验证材料）做端到端判据。

**执行裁决（2026-09-15，controller）：**
- **Ruling L（测试容器）**：systems/test_harmonic/ 放一个验证材料级容器
  （谐振 PES + 可选 term/classify 绑定），经 reg 文件拖入——它是判据材料
  （C4-C6 各 check 绑局部测试势传统的 driver 级等价物），不是 C2(interface)
  窗口保护的"首个真容器"（物理容器）。E20"主体以假想力链搭建"需要整程序
  可端到端运行，此为最小实现。
- **Ruling M（prop_reg 路线）**：骨架立法"driver 手写 prop_reg×3 闭族例外"
  与 C6 已落地的 reg_prop.f90（经 registry_gen 聚合）冲突——并存即重复注册
  loud-stop。裁定：**保留 reg_prop.f90**（E11 拖入统一性，driver 零手写注册
  的精神优先；骨架的闭族例外是 K3 过渡期刻痕，被 C6 的 reg 文件作废），
  driver 注记此偏离。
- **Ruling N（装配缝设计）**：分发行暂存值 → 成员 params_t 的装配经
  **reg 文件的 init 聚合**——每个 reg_dist_*.f90 增一个 init 例程（读 input
  公开暂存访问器 → 调本成员 init），registry_gen 聚合之；driver 调聚合入口。
  三方零知识保持：driver 不知成员、input 不知成员、成员不经手 driver。
  （C5 移交③"该缝须自带判据"在本计划落地：真输入文件 → 各员 init →
  参数 getter 回读断言。）
- **Ruling O（thermalize 整态语义）**：thermalize 经 prop_step 推进**全
  sta**（整 roster 平衡）为既定语义——不做旁观者冻结（C5 移交①关闭：
  冻结会越权成员分量所有权，整态语义最简且合法；头注已如此记载）。
- dt_eff 过渡语义（骨架既定）：elec_prop(sta, dt_eff) 收 prop_cfg%dt 暂存值
  ——radau 序列长 vs 固定 dt 的裁决点**开点 → C2(interface)**（E13 已把
  多表面 × radau 排除到成员侧 loud-stop，绝热路径无 dt 敏感性）。
