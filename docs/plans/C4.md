**目标：** 主体程序的第一块成真——**装配数据链**（体系定义文件 → sysdef_load →
roster_load）、**输入语法**（KEYWORD=VALUE → control/config 槽位 + 旧整数键回退 +
presets）、**记录框架**（recorder 列注册/选择/帧/终态），外加其依赖件 specio
（.xyz/POSCAR 读取 + IUPAC 质量表）。四件全部撤下伪代码，判据先行，check 程序
随行入 scripts/。

**范围裁定（拟）：**
- S1 **能量列数值后验**：recorder 的能量三列（t_kin/v_pot/e_tot）经 force_eval——
  C4 期 facade 仍是空转伪代码（E20 序的既定姿态）。列**机制**（注册/选择/格式/写序）
  以结构列 + 构造量判据；能量列数值验证延至 C2(interface) 之后的 V 相，此处记录在案。
- S2 **sysdef 的 roster 写手裁为暂存转移式**（E14/T11 的遗留 open point 在此关闭）：
  sysdef_load 的解析结果存 **sysdef 模块私有 staging**（不 use config_roster——门面间
  零模块依赖的立法保持），roster_load 从 staging 转移装配（分配+代数+验证不变）。
- S3 **input 键集第一版随本计划定稿，按逻辑两块组织（E21）**：**块一·计算流程控制**
  （这一轮怎么跑）与**块二·散射体系定义**（跑的是什么体系与初条件）。本程序独立——
  **旧整数键回退全部撤销**（E21：主计划全局约束 3 的回退句废止；与旧库的临时对照
  直接复用旧输入文件，不进本程序语法）；**container 已定义的内容（组分/质量/几何/
  晶胞/表面范式——sysdef 材料）一律不重复入语法**（E14 撤键原则升格为通则）。
  **MODEL 键与 presets 框架撤销**（E22）：预设体已被完全分解——范式由 sysdef 派生、
  表面细分归 C5 键、采样归 DIST_SCHEME、数值默认归成员参数；通用缺省改为**逐键默认**，
  原预设兜底的键（INTEGRATOR/DIST_SCHEME 等）入必键集或定逐键默认。
- S4 **specio 一并成真**（read_xyz / read_poscar / elem_mass——sysdef 的解析器面）。

**设计裁决（拟）：**
- D1 **发现规则**：扫 system_dir 下文件，文件名（去扩展名）= 反应物名；`.xyz` →
  无胞（分子范式）；`POSCAR*` → 含胞（表面范式候选）；n_frag = 体系文件数（**不输入**，
  E14"一反应物一文件"的推论）；空文件夹 loud-stop（装配错误）。
  〔单胞立法（C4.2 实现期 gap-fill，2026-09-14）：第二个 POSCAR 族文件 →
  loud-stop——roster 胞字段是系统级单件，双胞不可承载〕
- D2 **范式派生**：任一文件含胞 → surface_model 走表面（1/2 之分留输入或成员——
  E14 既定 open point，C4 先落"含胞→表面类(=1)、全无胞→分子(=0)"，1-vs-2 的细分
  键（SURFACE_MODEL）留 C5 表面成员窗口）。
- D3 **recorder 列集第一版**：框架预注册列 = 能量三列 + 结构列（q/p 六元组行、
  per-atom 力行）+ 步号/时间/轨迹号帧头；GWRITE_LEVEL 四级 → 预设列组（表驱动，
  N3.1）；OBSERVABLES= 名单与预设并存。E16/E19 观测源立法（occ/n_hop 经 getter）
  随 getter 空转可用（占位列注册，数值后验）。
- D4 **roster_load 验证集**：逐片段 nat ≤ 原子数、list 索引界内、质量全正、
  表面范式 a_lat ≤ 0 → loud-stop 点名缺晶格常数（E12 裁定原文行为）。
