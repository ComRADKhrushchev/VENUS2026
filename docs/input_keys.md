# input_qct.txt 输入键说明

基本格式：
- `KEYWORD = VALUE`；
- 可通过`#`/`!` 整行注释；在行尾写 `,` 可以续行；
- 关键字名大小写不敏感；一键仅允许出现一次，未知/重复键指名中止。  

单位制：
- 能量 eV，长度 Å，时间 fs，温度 K，角度 rad。
  
键表的定义参见 `src/input.f90`, 如有冲突，以源代码为准；


## 常用关键字
- 基本计算流程控制，一般必须写；

| 键 | 默认 | 含义 |
|---|---|---|
| `TASK` | `TRAJECTORY` | 任务类型（目前仅此一个合法输入） |
| `N_TRAJ` | `1` | 轨迹条数 |
| `INTEGRATOR` | `VERLET` | 积分器：`VERLET` / `SYMPLECTIC` / `RADAU` |
| `ORDER` | `1` | 积分器阶：verlet 1=velocity-Verlet、2=三阶 Beeman；symplectic 组合阶 4/6/8 |
| `ISEED` | `1` | 随机流种子 |
| `MAX_STEPS` | `100000` | 每轨迹步数上限（安全网；无终止判据时跑满为止） |

## 入射通道参数
- 弹丸的入射方式：控制碰撞能、方向与落点；

| 键 | 含义 |
|---|---|
| `N_E_REL` | 碰撞能模式：0=热分布 / 1=定值(给定`E_REL`) / 2=密度加权 |
| `T_TRANS` | 平动温度 [K]（N_E_REL=0 时须 >0） |
| `V_WIDTH` | 速度展宽 [Å/fs]（N_E_REL=2 时须 >0） |
| `N_THTA` | 极角模式：0=固定 / 1=按 sinθ 采样 |
| `THTA_MAX` | 极角界/固定值 [rad]（0..π/2） |
| `N_CHI` | 方位角模式：0=固定 / 1=均匀采样 |
| `CHI` | 固定方位角 [rad]（N_CHI=0 时用） |
| `N_B` | 瞄准模式：0=固定 b=B_MAX / 1=碰撞盘采样（B_MAX=0 须 N_B=0） |
| `N_AIM` | 落点模式：0=原点 / 1=胞内均匀 / 2=定点（模式 2 仅表面散射） |
| `AIM_X` / `AIM_Y` | 定点落点 x/y [Å] |

## 必需关键字
- 无论什么体系都必须写的关键字

| 键 | 含义 |
|---|---|
| `DT` | 积分时间步长 [fs] |
| `SYSTEM_DIR` | 反应物构型文件夹：每片段一个 `.xyz` / `.poscar`，文件名 = 片段名（文件只携带几何；`.poscar` 的胞仅作该文件 Direct 坐标的参考架，体系胞由 CELL 键给出） |
| `E_REL` | 碰撞能 [eV] |
| `R_SEP` | 初始质心间距（投放距离）[Å] |
| `DIST_SCHEME` | 每个片段的采样方案，逗号分隔，**词数 = 片段数**；词可带括号参数：`词[参数=值, ...]`（见下文采样方案自带参数） |

## 条件关键字
- 填写方式与散射类型（`SCATTERING`）相关的关键字

| 键 | 含义 | 表面散射填写 | 气相散射填写 |
|---|---|---|---|
| `SCATTERING` | 决定体系是表面散射还是气相散射 | `SURFACE` |`GAS` |
| `CELL` | 晶胞三行晶矢 [Å]| 如 `6 0 0, 0 6 0, 0 0 20` | 不支持 |
| `PROJECTILE` | 作为弹丸的分子片段的名称 | 分子片段名称 | 与 `TARGET` 不同名的片段 |
| `TARGET` | 作为靶的分子片段名 | 不支持（默认表面为靶） | 与`PROJECTILE`不同名的片段 |
| `B_MAX` | 碰撞参数最大值 [Å] | > 0的数值 |不支持（表面晶格随机入射）|

## 可选关键字
- 不写即取默认值；

| 键 | 默认 | 含义 |
|---|---|---|
| `TITLE` | （空） | 输出中的标题行 |
| `ELEC_METHOD` | `ADIABATIC` | 非绝热方法的注册名，参见自定义PES接入说明 |
| `GWRITE_LEVEL` | `2` | 记录级别，限 {0,1,2,5}：≥2 记每步 q/p，≥5 额外写入受力 |
| `OBSERVABLES` | （空） | 让程序额外输出的物理量的名称 |
| `RANDOM_ORIENT` | `F` | 是否随机化各片段的初始构型 |
| `BATH` | `NONE` | 是否在轨迹开始前做热浴：`NONE` / `ANDERSEN` |
| `N_BATH` | `0` | 浴循环步数 |
| `DT_BATH` | `0.0` | 浴循环步长 [fs] |
| `SPECTRUM_SOURCE` | `COMPUTE` | 振动谱（部分采样方式需要）的计算方式：`COMPUTE` =  Hessian 直接计算；`MANUAL` = 手动输入参数 |
| `SPECTRUM_FILE` | （空） | 谱表文件路径（须 `SPECTRUM_SOURCE=MANUAL`；） |

## 采样方案自带参数（DIST_SCHEME 括号）
- 各采样方法的参数只随 DIST_SCHEME 的括号给出（2026-10-13 裁定）：
  `DIST_SCHEME = 词[参数=值, 参数=值], 词[...], ...`——不设顶层成员键、
  无任何回退；写了括号的片段自洽，裸词片段走成员默认；
- 逐片段独立：同一词的两个片段可带不同参数（如两个 EBK 片段各处一个量子态）；
- 参数名不是该词的参数、或同一括号内重名，均在解析时指名中止。

| 方案词 | 括号参数 | 含义 |
|---|---|---|
| `BOLTZMANN` | `T_VIB` | Boltzmann 振动温度 [K]（须 >0，必给） |
| `EBK` | `N_VIB` / `N_ROT` | 振动/转动量子数（≥0，缺省 0；载体须双原子） |
| `ROTATION` | `J_ROT` | 固定转动角动量量子数 J（≥0，缺省 0；该成员自带取向，不受 RANDOM_ORIENT 复转） |
| `J` | `T_ROT` | 转动温度 [K]（须 >0，必给） |
| `SURFACE_OSCILLATOR` | `N_OSC` | 振子模式：0=热 / 1=定态（缺省 0） |
| | `T_OSC` | 振子温度 [K]（缺省 300；N_OSC=0 时须 >0） |
| | `N_LEVEL` | 定态能级（≥0，缺省 0，N_OSC=1 时用） |
| | `K_OSC` | 振子力常数 [eV/Å²]（缺省 1.30092582，须 >0） |
| `NORMALMODE` | `E_VIB` | 振动能 [eV]（缺省 0.43364194，须 >0） |
| `BARRIER_EXCITATION` | `E_STAB` | 鞍点稳定模分能 [eV]（≥0，缺省 0.34691355） |
| | `N_E_BAR` | 反应坐标能量模式：0=定值 / 1=热（缺省 0） |
| | `E_BAR` | 反应坐标能量 [eV]（≥0，缺省 0.21682097） |
| | `T_BAR` | 反应坐标温度 [K]（缺省 900，N_E_BAR=1 时须 >0） |
| `GLO_TARGET` | `T_GLO` | GLO 靶温 [K]（须 >0，必给） |
| | `GAMMA_GLO` | GLO 摩擦系数（须 >0，必给） |
| | `W_GHOST` | ghost 频率 [1/fs]（须 >0，必给） |
| `THERMALIZE` | `T_EQ` | 平衡温度 [K]（须 >0，必给） |
| | `N_EQ` | 平衡步数（≥1，必给；各 THERMALIZE 片段须一致——平衡跑共享一次） |
| | `DT_EQ` | 平衡步长 [fs]（须 >0，必给；同上须一致） |
| `WIGNER` | `E_SCALE` | Wigner 能量标度（零点能份额，缺省 1，须 >0） |

浴物种参数（`BATH = ANDERSEN` 时的 `T_BATH` / `NU_COLL`）与入射通道参数
（束流键）是通道级成员键，仍为顶层键（见上文各组）。

示例（两个 EBK 片段各处一个量子态）：

```
DIST_SCHEME = EBK[N_VIB=0, N_ROT=2], EBK[N_VIB=3, N_ROT=1]
```

注：WIGNER / NORMALMODE / BOLTZMANN 从谱拉模表、EBK 拉双原子常数——谱由
`SPECTRUM_SOURCE` 独占选择（EBK 无推导通道，COMPUTE 下拉即中止并指名 MANUAL）。

## 容器键

由拖入的物理系统容器声明（Tier 1 的 `keys()` / Tier 2 reg 的 declare_keys），随
input_qct.txt 一起写，如 reference 容器的 `K_HARM` / `Q_TERM` / `E_SPLIT`。不得与
程序键/成员键撞名（声明即中止）；缓冲而未被容器消费的键在装配审计中止。接入
自定义势能面见 [custom_pes.md](custom_pes.md)。
