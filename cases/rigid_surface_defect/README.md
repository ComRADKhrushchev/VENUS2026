# rigid_surface — 刚性表面（NSURF=2）修复回归验证

> 运行：`cd cases/rigid_surface_defect && ../../venus_test.e`（主输入 `input_qct.txt`）
> 注：越界读修复后仍非逐位确定（ISEED 相关）——双跑差异属随机数路径，非缺陷。

## 1. 目的

刚性表面（NSURF=2）历史缺陷的修复回归验证：损坏签名（非有限值全传播）
必须消失，束流组装必须保持精确。

## 2. 理论与体系

体系为 TEST 势 HARMONIC；A 单原子气体（入射高度 8.0 Å），B 4 原子表面。
历史四重缺陷（预设语义/QZB_EQ 读取/胞定义越界读/五坐标采样）中前三项已修复，
第四项部分实现。

## 3. 方法与流程

读取输入→初始化随机数（ISEED=20260834）→NT=20 条轨迹走 NSURF=2 斜胞
入射链（fort.88 记录瞄准点 RX0/RY0）→每轨迹传播 NS 步（fort.1001–1020）。

## 4. 核心验证

见 `fig_long_trajectory.png`。

> 图注：A 原子 z(t) 从 8.0 Å 起步下降，全部数值有限（0 个非有限值）。
> 判定依据：fort.88 瞄准点 RX0/RY0 全部有限；H 守恒极差 0.0000。
> 长时程穿透（z 越过 0 平面）为 HARMONIC 测试势固有属性（方格表面无
> 近距排斥），真实刚性表面散射应使用 EMT-NN 势。
