# 玻尔兹曼振动采样（BOLTZMANN-VIB）— 几何分布振动态

> 运行：`cd cases/boltzmann_vib && ../../venus_test.e`

## 验证目的

验证玻尔兹曼振动采样（`INIT_SAMPLING_A=BOLTZMANN-VIB`）在 LEPS 等边 H₃ 体系上的
统计正确性（NT=1000，`TVIB_A=2000 K`）：每模量子数服从几何分布、平均能量与
温度定义一致。

## 原理

体系：TEST 势 LEPS 等边 H₃ 极小（E′ 对 1013.5 cm⁻¹，呼吸模 1803.8 cm⁻¹）。
机制链与固定量子数采样（NACT=3）相同，仅量子数来源不同：由 `THRMAN` 按几何分布
逐模抽取——GAMA=−ln(U) 服从指数分布，n=trunc(GAMA/DUM)，
DUM=1.43878·ν/T=hν/k_BT；故 P(n)=(1−q)qⁿ，其中 q=exp(−hν/k_BT)。

T=2000 K 时 q(E′)=exp(−1.43878×1013.47/2000)=0.482、q(呼吸)=0.273，
平均占据 ⟨n⟩=q/(1−q)=0.93/0.93/0.38。EVIBA 应等于 Σ(n_i+½)ω_i（谐波能级和），
解析期望 E[EVIBA]=12.815 kcal/mol。随后能量闭合缩放至完整非谐 LEPS 势。

## 预期与结果

- **每模几何分布命中**：三模 KS 统计 Dmax=0.0197/0.0101/0.0142 ≤ 3/√N=0.0949，
  直方图单调递减形态与各自 q 值吻合 ✓
- **平均能量解析闭合**：EVIBA 均值 12.702 vs 解析期望 12.815 kcal/mol
  （相对偏差 0.0088，门限 2%）✓
- **单轨迹能量自洽**：EVIBA=Σ(n_i+½)ω_i 逐轨迹成立（最大相对偏差 0.0010）✓
