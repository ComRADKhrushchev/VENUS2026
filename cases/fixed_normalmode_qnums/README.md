# 固定简正模量子数（NORMAL-MODE）— 谐波能级 (n+½)ℏω 分配

> 运行：`cd cases/fixed_normalmode_qnums && ../../venus_test.e`

## 验证目的

验证固定简正模量子数采样（`INIT_SAMPLING_A=NORMAL-MODE`）在 LEPS 等边 H₃ 体系上的
正确性（NT=1000）：用户固定 `ANQ_A=(1,2,3)`，考察量子数回显、谐波能级能量值、
以及逐轨迹能量集中度（能量固定、相位随机）。

## 原理

体系：TEST 势 LEPS 等边 H₃ 极小（E′ 二重简并对 1013.5 cm⁻¹，A₁′ 呼吸模
1803.8 cm⁻¹）。机制链与微正则简正模采样相同（`NMODE` → `INITQP`），仅能量分配
步骤不同：每模取谐波能级 (n_i+½)ℏω_i。本 case 谐波能级和

  E = [1.5×1013.47 + 2.5×1013.51 + 3.5×1803.83] / 349.755 = 29.64 kcal/mol

（349.755 为 cm⁻¹→kcal/mol 换算因子）。随后能量闭合缩放至完整非谐 LEPS 势，
EVIBA 应落在谐波能级 0.5% 内；随机相位由 `INITQP` 逐轨迹重抽——能量固定、
相位随机，是固定量子数语义的关键。

关联缺陷：`NACTA=4`（LOCAL-MODE 局域模）的 Morse 参数在 fork 中无输入来源，
W(0) 越界 → NaN 与死循环，登记为缺陷 **F20**（不修）。

## 预期与结果

- **谐波能量解析闭合**：EVIBA 均值 29.636 vs 解析 29.642 kcal/mol（相对偏差
  0.0010，门限 0.5%）✓
- **能量集中度**：1000 条轨迹 EVIBA 展宽仅 0.059 kcal/mol（< 0.1）——闭合缩放
  几乎不改变固定能级，相位是唯一的逐轨迹自由度 ✓
- **量子数回显**：stdout 回显 [1.0, 2.0, 3.0] 与输入 `ANQ_A` 一致 ✓
