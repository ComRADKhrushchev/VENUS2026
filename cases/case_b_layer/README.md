## 1. 验证目的

C5-R1 法定收口：B 层三员在**真力链**下的数值后验。C5 期的
check_dist_{thermalize,thermostat,glo_target} 是机制+代数版（合成参数、语法表不在环）；
本 case 把三员的判据升为链上数值版——真输入文件、真装配链、真传播：

- **thermalize**：成员声明的平衡后动能期望 E[KE] = (3nat−3)·kb·T_EQ/2（Maxwell 种子 +
  精确 COM 投影移除整 3 个自由度）以**精确 χ² 统计带**验证（首帧 = 平衡后状态）；
- **thermostat**：速度重置后的动能目标带——逐分量重抽、**无投影**（成员语义如此，
  刻意与 thermalize 的投影对照）→ χ²_(3nat) 精确带；
- **glo_target**：涨落-耗散装载的链上一致性——σ_noise² = 2γm·kbT/dt 经**真装配链**
  （read_input → sysdef → list_atoms → registry 初始化组装机构）的 getter 回读 vs 手算（探针
  probe_glo.f90，解析后验——按简报不跑长程统计）。

## 2. 原理

布局与体系（三子文件夹各持两件套：input_qct.txt（含容器键）/ system/）：

- `thermalize/`、`thermostat/`：H4 线型片段（4 个 H，等质量 1.008 u——等质量是
  单频相干设计的必要条件）；`glo/`：HCl 片段（1.008 / 35.45 u 不等质量——逐原子
  σ 检查更锐利）。
- 物理系统容器均为 reference 谐振井：容器键仅 `K_HARM = 0.04`（随 input_qct.txt）（Q_TERM/E_SPLIT
  刻意缺席——安全网式无分类跑，统计面 `outcome counts: none`；无中途终止 →
  每轨迹恰 MAX_STEPS+1 帧，帧统计样本量确定）。
- 单片段气相（paradigm=0）：incident 通道不派发（samp_run 的 n_frag>1 或表面范式才
  派发）——E_REL/B_MAX/R_SEP 为语法必键占位（V.2 同姿态）。
- 换算（沿 V.1 第 2 节）：conv = ev_kcal·e_conv = 23.0605×0.04184 = 0.964851
  A²·u/(10 fs)²每 eV/u；井中每原子 ω = √(conv·K/m_H) = 0.1956726/(10 fs)。

**thermalize（相位返回设计）**：成员语义 = Maxwell 种子（σ² = m·kb·T_EQ 逐分量）+
精确漂移移除（质量加权 COM-速度投影，移除整 3 个自由度——任意质量分布下
KE_seed = (kb·T/2)·χ²₉ 精确成立，H4 的 12 分量 − 3）+ N_EQ 步注册传播器（verlet，
全局步长换至 DT_EQ 再复原）。关键链上事实：单片段气相下无人写 q → 平衡从 q≡0 出发；
线性井上 verlet 是**精确旋转**（每步转角 θ(h) = 2·arcsin(ωh/2)，vv_advance 每步
左端力新算——无陈旧力污染），种子态绕单一频率相干旋转。取
**N_EQ=320、DT_EQ=0.0502**：θ_eq = 2·arcsin(0.1956726×0.0502/2) = 0.009822802，
320·θ_eq = 3.1432966 = **π + 0.0017040** → cos² = 0.9999971——平衡恰为半周回位，
**首帧 t_kin = KE_seed·(1 − 2.9e-6)**，成员声明的 χ²₉ 期望被定在帧面上。
推导余项：θ(DT=0.05) = 0.0097836670；帧 322（n=321 步）相位
φ₀+321θ = 2π+0.0006684 → t_kin(322)/t_kin(1) − 1 = +2.5e-6（周期回位副判据）；
轨迹 1 的谷底（首个下行谷相位 **3π/2**——φ₀ ≈ π 之后 [V.5 勘误：原误书
π/2 族]，最近格点 n=160）t_kin ≈ E·sin²(θ/2 量级) ~ 1e-7。

**q 链式携带（试跑发现，诚实入档）**：驱动器的新轨迹复位**只清 sta%t**（注册的
编排语义：采样成员只写自己拥有的分量；单片段气相热化跑里无人写 q）→ 轨迹 2 起
平衡从上一轨迹的**末帧 q** 出发。后果（试跑定量）：
(i) **首帧动量统计不受染**——携带交叉项 |mω̃·q_prev·sinφ₀| ≤ 1.008×0.1957×1.3×0.0017
≈ 4e-4，对 p ~ 0.2 的相对污染 ~2e-3，远在统计带内（试跑 8 轨迹首帧均值 2.672 vs
期望 2.683，落 χ²₇₂ 带中心）；(ii) 相干节点格只在**轨迹 1**（新生态）保持——
轨迹 2+ 各分量相位混合，节点结构洗掉、帧均值比获得 +0~2% 携带加成（试跑总体比
0.511，轨迹 1 比 0.4985）。判据此设计：结构腿定在轨迹 1，均值腿定在全 32 条。
该语义本身合法（无合同被违反——散散射跑里 incident 通道每轨迹重写 q，不可见），
登记为 V 发现清单的**观察项**（非缺陷），详见任务报告。

**thermostat**：成员 = 逐分量 Maxwell 重抽（σ² = m·kb·T_BATH），**无投影**——速度
重置语义刻意保留总动量涨落 → 首帧 KE = (kb·T/2)·χ²₁₂ 精确（12 分量整），且 p 被
整体覆写、与 q 携带完全无关。NU_COLL 为携带数据（当前无消费面——注记非判据）。
T_BATH = 350 K 与 thermalize 的 300 K 区分（两带不重叠——带心 4.173 vs 2.683）。

**glo_target（静态取证 + 探针）**：成员 = init 装载（σ_noise² = 2γm·kbT/dt、
σ_p² = m·kbT、σ_q² = kb·T/(m·ω_ghost²)，dt 取初始化组装机构上读到的传播器步）+ 采样画
ghost 稳态（成员产物，**不写真态任何分量**）。真态 q=p≡0 → 井力为零 → 本跑
**静态**：全部帧 t_kin = v_pot = e_tot = 逐位 0（"ghost 不触真态"的位级证词）。
数值后验主体 = probe_glo.f90：真装配链（驱动器装配步 1/3/4/6/7——无需 rng 与
state）后，getter 回读 vs 手算（输入字面量 + 探针内写死的 IUPAC 质量——与 list_atoms
的符号→质量解析**不同路**）：(a) T_GLO/GAMMA_GLO/W_GHOST/DT 装载完整性；
(b) 载体绑定（片段 1、nat=2、ghost 尺寸 6）；(c) list_atoms 质量路线 vs 手写值；
(d) **σ_noise² = 2γm·kbT/dt 逐原子**（H 0.644093 / Cl 3.819673——不等质量锐化）；
(e) σ_p²、σ_q² 平稳宽度代数；相对容差 1e-12，exit 0/1。

**两段式标定（判据先行）**：先试跑（pilot，2026-09-15：N_TRAJ=8、ISEED=20260900、
三子文件夹同布局；产物已删不入档）验证模型腿——首帧均值落 χ² 精确带内
（thermalize 2.672、thermostat 4.010）、轨迹 1 相干结构逐项命中（v_pot(1)/t_kin(1)
= 2.9e-6、t_kin(322)/t_kin(1) = 1+2.5e-6、min = 2.9e-8）、帧均值比 0.4985/0.511、
glo 全零 + 探针 14/14 绿；正式判据随后写定（本节），先于正式跑。

## 3. 预期判据（先写后跑——判据先行；正式跑 N_TRAJ 与 ISEED 见各 input_qct.txt）

通用（三跑同构）：

- **S1 装配/统计面行**：退出码 0；assembly 行逐字（therm*：
  `trajectories=32 atoms=4 fragments=1 paradigm=0 members=11 init=ok columns=3`；
  glo：`trajectories=4 atoms=2 ...`）；statistics 行 valid 全额；结局行
  `outcome counts: none (no classification bound - skipped)`；drift/直方图行存在。
  直方图双退化说明（预期形态非缺陷，V.1 thta 退化 + V.2 e_rel 退化的合取）：
  单片段气相 e_rel ≡ 0 且 thta ≡ 0 → hist_e_rel/hist_thta 皆退化 bin-1 全计。
- **S2 守恒**：帧级 |e_tot − 本轨迹首帧 e_tot| ≤ **5.0e-3 kcal/mol**（打印行同界）。
  推导：verlet 阴影哈密顿量守恒，简谐模能量偏移 ~ (ω·dt)²×能标——thermalize/
  thermostat (0.1957×0.05)² = 9.57e-5 × 能标 ~2.7/4.2 → 界 ~2.6e-4/4.0e-4；判据
  5.0e-3 取 ≥12× 裕度；glo 静态期望**逐位 0**（井对全零态零力）。
- **S3 确定性**：同输入两次运行 trajectories.txt 逐字节一致（rng 单流 + 固定算术）。

**thermalize（T 系）**：

- **T1 首帧均值带（主判据）**：32 轨迹首帧 t_kin 均值 ∈ **[2.141, 3.294] kcal/mol**。
  推导（自由度/样本量/置信水平全部写明）：每轨迹首帧
  t_kin = (kb·T_EQ/2)·χ²₉/e_conv×(1−2.9e-6)——ν = 9 = 12 分量 − 3 投影；32 轨迹
  iid，独立 χ² 可加 → 均值 = (kbT/2)·χ²₂₈₈/32/e_conv **精确分布**（无 CLT 近似）；
  μ = (9/2)·kb·300/e_conv = 2.682706；χ²₂₈₈/288 的 99% 中心分位（scipy 精确值，
  Wilson-Hilferty 复核至 5e-5）= [0.7984, 1.2277] → 带 [2.1419, 3.2935]，判据取
  [2.141, 3.294]（双侧 99%，失败率 1%）。
- **T2 轨迹 1 相干结构（相位返回设计腿，确定性）**：轨迹 1（新生态）
  v_pot(step1)/t_kin(step1) ∈ **[2.5e-6, 3.5e-6]**（= sin²(0.0017040) = 2.904e-6）；
  t_kin(step322)/t_kin(step1) ∈ **[0.999, 1.001]**（设计值 1+2.5e-6）；
  轨迹 1 全帧 min t_kin < **0.01**（设计 ~1e-7，试跑实测 2.9e-8）。
- **T3 分配腿（帧均值/首帧比）**：轨迹 1 比 ∈ **[0.496, 0.501]**（确定性窗口值，
  试跑定标 0.4985——纯模型 Dirichlet 项 +0.32% 按实现窗口相位修正为 −0.3%）；
  全 32 轨迹总体比 ∈ **[0.495, 0.520]**（窗口展宽 + q 携带 +0~2% 包络，试跑
  0.511）。物理含义：相干单频井中时间平均动能 = 总能之半（维里定理），与 T1
  合起来即"每自由度 ⟨KE⟩ = kbT/2、⟨E⟩ = kbT"的分配自洽。

**thermostat（H 系）**：

- **H1 重置后动能带（主判据）**：32 轨迹首帧 t_kin 均值 ∈ **[3.437, 4.991] kcal/mol**。
  推导：首帧 t_kin = (kb·T_BATH/2)·χ²₁₂/e_conv——ν = 12 = 12 分量整（无投影）；
  32 轨迹 iid → 均值 = (kbT/2)·χ²₃₈₄/32/e_conv 精确分布；μ = 6·kb·350/e_conv =
  4.173098；χ²₃₈₄/384 的 99% 中心分位 = [0.8239, 1.1957] → 带 [3.4382, 4.9896]，
  判据取 [3.437, 4.991]（双侧 99%）。
- **H2 记录器算术交叉核**：首帧 sec_qp 动量独立重算 t_kin = Σp²/(2m)/e_conv
  （m = 1.008），逐轨迹与打印列相对偏差 ≤ **1e-10**（帧打印 16 位有效数字）。

**glo（G 系）**：

- **G1 静态跑**：全部 4 轨迹×11 帧 t_kin = v_pot = e_tot = **逐位 0.0**；drift 行
  `max|e_fin-e0|=  0.0000E+00`。（ghost 采样消费 rng 流但写真态零分量——四条
  轨迹产物逐位相同亦为该契约的证词。）
- **G2 装载链探针**：`probe_glo.exe` 退出码 0，14 项检查全 PASS 且相对误差
  ≤ 1e-12（实测 0.00E+00——位级一致）；含 FDT 主判据
  σ_noise(H) = √(2×0.09×1.008×kb×550/0.02) = 0.64409262、
  σ_noise(Cl) = √(2×0.09×35.45×kb×550/0.02) = 3.81967293。

份额对前 31 条的链代数均值 ≈ 0.106 → 预测总体比 ≈ 0.553（先验包络
0.51–0.56），实测 0.538494 落在包络内——**主体行为与线性代数完全一致，
出带是试跑标定失误**（N=8 只见链头，欠采样暂态；教训：试跑长度须超过
链的混合时间，此处 ~139 窗）。T1 主判据不受染（§2 预言的交叉项 ~4e-4 对
带 ±20%，实测带心比 0.954 证实）。该判据按判据先行纪律**保持原样**，本条
连同 q 链观察一并入 V 发现清单（任务报告）。
