# 固定 n,J 的 EBK 采样 — 双原子量子态初始条件

> 运行：`cd cases/ebk_fixed_nj && ../../venus_test.e`

## 验证目的

验证 EBK（Einstein-Brillouin-Keller）固定振动/转动量子态采样在 MORSE 双原子上的统计
正确性：固定振动量子数 n=3、转动量子数 J=2，采样 999 条轨迹，考察 EBK 态不变性、
核间距分布的 WKB 密度命中、以及振转能量的解析闭合。

## 原理

体系：TEST 势 MORSE 双原子（H₂：De=4.746 eV、re=1.401 Å、a=1.028 Å⁻¹，约化质量
μ=0.5040 u）。机制链：`NACTA=0`（双原子 MB/EBK 分支）+ `TRV_A<0`（固定量子数标志）
→ `INITEBK` 逐轨迹采样。采样按 WKB 经典密度进行：核间距概率密度 p(r)∝1/|p_r(r)|，
径向动量 PR=√(2μ·SUMM(r))（SUMM 为有效势），符号以 50% 概率翻转；经典可达域由
EBK 能量的转折点 [RMIN, RMAX] 限定。

EBK 能级（含非谐修正与刚性转子项）：

  EVIBA = hc[ωe(n+½) − ωexe(n+½)²] + hc·Be·J(J+1)

MORSE 谱常数 ωe=2326.4 cm⁻¹、ωexe=35.35 cm⁻¹；n=3、J=2 时解析 EVIBA=22.3347 kcal/mol。

## 预期与结果

- **EBK 态不变**：ENJA/RMIN/RMAX 跨 999 个采样相对展宽全为 0（固定 n,J 语义严格成立）✓
- **r 分布命中 WKB 密度**：KS 统计 Dmax=0.0254 ≤ 3/√N=0.0949；实测可达域
  [1.0431, 1.9820] Å 与解析转折点 [1.0430, 1.9820] Å 一致 ✓
- **EVIBA 解析闭合**：程序值 22.3134 vs 解析值 22.3347 kcal/mol，相对偏差
  9.6×10⁻⁴（门限 0.5%）✓

补注：径向动量对给定 r 唯一确定（PR=√(2μ·SUMM(r)) 曲线最大相对偏差 3.5×10⁻¹²）；
PR 符号正号率 0.530，符合 50% 随机翻转语义（N=999 时 3σ≈±0.016）。
