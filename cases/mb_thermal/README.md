# 热 n,J 采样 — 量子热振动/转动态分布

> 运行：`cd cases/mb_thermal && ../../venus_test.e`

## 验证目的

验证量子热 n,J 采样（`NACTA=2`）在 MORSE 双原子上的统计正确性：以
`TRV_A=TROT_A=2000 K` 从热分布采样 1000 个 (n,J) 态，考察振动量子数的几何分布、
转动量子数的核自旋加权分布、以及 EBK 固定点采样的确定性。

## 原理

体系：TEST 势 MORSE 双原子（H₂：De=4.746 eV、re=1.401 Å、a=1.028 Å⁻¹，μ=0.5040 u）。
机制链：`NACTA=2` → `THRMAN`（振动量子数几何分布抽样）→ `PROBJ`（转动量子数加权
分布抽样）→ `INITEBK`（按 (n,J) 态采样核间距与径向动量 PR=√(2μ·SUMM(r))）。

- **振动**：n 服从几何分布 P(n)=(1−q)qⁿ，q=exp(−hcν/k_BT)；T=2000 K 时 q=0.1876。
- **转动**：J 服从 WGT(J)·(2J+1)·exp(−B·J(J+1))，B=48.5085/(2·AIA·T)（AIA 为转动
  惯量 [amu·Å²]），并含 H₂ 正/仲核自旋权重 0.75/0.25；T=2000 K 时 B=0.012259。

（`NACTA=0` 且 `TRV_A≥0` 为经典 Maxwell-Boltzmann 分叉，不在本 case 范围。）

## 预期与结果

- **n 几何分布命中**：KS 统计 Dmax=0.0176 ≤ 3/√N=0.0949，q=0.1876；直方图
  n=0..5 为 830/141/24/5/0/0，呈几何衰减 ✓
- **J 分布与核自旋权重命中**：KS Dmax=0.0129 ≤ 0.0949；偶/奇 J 计数 287/713，
  与正/仲氢统计权重 0.75/0.25 一致 ✓
- **(n,J) 态确定性**：ENJA 由 (n,J) 对唯一确定（位级失配 0），范围
  [0.1381, 1.2230] ⊂ (0, De)（code 能量单位）✓

补注：597 条 `FINLNJ` 诊断行为 INITEBK 在 n=0/ZPE 边界的已知提示噪声，
全部轨迹正常收敛退出，非失败项。
