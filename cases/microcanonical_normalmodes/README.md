# 微正则简正模采样 — 固定内能的模能量分配（含 F19 缺陷签名）

> 运行：`cd cases/microcanonical_normalmodes && ../../venus_test.e`

## 验证目的

验证微正则简正模采样（`INIT_SAMPLING_A=MICROCANONICAL`）在 LEPS 等边 H₃ 体系上的
统计正确性（NT=1000，固定内能 `ENMT_A=1.0 kcal/mol`、转动能 0）：简正模频谱、
模间能量分配、能量闭合——并锁定祖传缺陷 F19（振动角动量剥离）的确定性签名。

## 原理

体系：TEST 势 LEPS（Sato Δ=0.164）等边 H₃ 极小。简正模频谱：三个平动模 <1 cm⁻¹，
E′ 二重简并对 1013.5 cm⁻¹（切向），A₁′ 呼吸模 1803.8 cm⁻¹（径向）。

机制链：`select_polyatomic_a` → `NMODE`（频谱与简正向量）→ 序贯能量抽样
（各模份额 p_i = rest·(1−u^(1/(NMBAR−i)))，rest 为剩余能量；该构造在数学上等价于
均匀 Dirichlet(1,1,1) 分布）→ `INITQP`（相位组装 + 振动角动量剥离；随后能量闭合：
P 与 (Q−QZ) 同乘 √(HSCALE/H)，直至 |H−HSCALE|/HSCALE ≤ 10⁻³，NSCALE≤50）。

**F19（登记不修）**：`INITQP.f:131-137` 的 VENUS96 祖传振动角动量剥离——向体系加入
相消刚体旋转，而惯量张量依赖瞬时畸变几何，剥离过程非线性——系统性把呼吸模能量
转入 E′ 简并对：无偏应为 (⅓,⅓,⅓)，实际 (0.40, 0.40, 0.20)。该签名与能量、构建
无关，本 case 将其作为确定性锚点锁定而非失败项。

## 预期与结果

- **能量闭合**：1000/1000 轨迹末态内能相对 ENMT_A 的偏差 ≤10⁻³（最大值恰好命中
  门限，缩放循环按设计工作）✓
- **频谱锚点**：振动三模 1013.47/1013.51/1803.83 cm⁻¹（容差 ±1 cm⁻¹），
  平动模 <1 cm⁻¹ ✓
- **F19 签名**：呼吸模能量份额均值 0.2008 ∈ [0.17, 0.24]（无偏应 0.333），
  E′ 对合计 0.7992，逐位可复现 ✓

补注：F19 为祖传行为，凡依赖微正则简正模初始条件的统计结论均须携带此偏置。
质心动量去除 max|Σp|=1.0×10⁻⁵（CENMAS）。
