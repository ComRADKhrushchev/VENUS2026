# 量子微正则采样（QM-MICRO）— 量子数态密度取态

> 运行：`cd cases/qm_micro && ../../venus_test.e`

## 验证目的

验证量子微正则简正模采样（`INIT_SAMPLING_A=QM-MICRO`，NACTA=8）在等边 LEPS H₃
上的正确性（NT=100，`ENMT_A=8.38 kcal/mol`）：量子数守恒、能量不可达模拒绝、
简并对均匀取态、能量闭合、双跑逐位确定。

## 原理

体系：TEST 势 LEPS 等边 H₃（E′ 对 1013.5 cm⁻¹，呼吸模 1803.8 cm⁻¹）。

机制链：`QMMICRO`（手册外扩充，前 fork 谱系继承）——可用量子能量
DUM1=(ENMT_A−ZPE)·CAL2CM（cm⁻¹）；高频模以均匀候选经 Beyer-Swinehart 态密度
拒绝（DENQ 比值裁决）；末 2 模在 ±100 cm⁻¹ 容差网格上枚举均匀取态。

本 case 的态选择：DUM1=1015.7 cm⁻¹——呼吸模（1803.8 cm⁻¹）不可达（占据将留
负剩余能量 → DENQ 拒绝，物理正确）；E′ 简并对恰接纳 (1,0)/(0,1)（2 态均匀）。
全链跑 RAND0(ISEED)，无系统种子依赖 → 双跑逐位确定。

登记限制（本 case 未触发）：若 DUM1 使网格枚举 SCOUNT=0，`QMMICRO.f:94-106` 留
ANQ(1)/ANQ(2) 未赋值——其他 ENMT_A 值下的潜在隐患。

## 预期与结果

- **量子数守恒**：Σ(n1+n2)=100=NT、Σ(n3)=0（态密度拒绝正确阻止高模占据）✓
- **简并对均匀**：(1,0,0) 占比 57/100（理论 0.5，∈ [0.3, 0.7]）✓
- **能量闭合**：max|E_vib−ENMT_A|=2.07 cm⁻¹，远小于网格容差 ±100 cm⁻¹
  （E_vib 2928.9 vs 2930.9 cm⁻¹）✓

补注：第二能量点（ENMT_A=11.19 kcal/mol）网格枚举三态均匀（χ²=1.24，p=0.54），
佐证取态在多个能量点精确均匀。双跑逐位一致（106/107 fort 文件一致，stdout 仅
运行耗时行差异）。
