# rigid_surface — 刚性表面（NSURF=2）束流散射

> 运行：`cd cases/rigid_surface && ../../venus_test.e`（主输入 `input_qct.txt`）
> 注：复跑非逐位一致（随机数路径差异，非缺陷），验收以统计量为准。

## 1. 目的

验证刚性表面（NSURF=2）分支的束流组装与动力学：斜胞内瞄准点均匀抽取、
入射方向按斜胞几何组装、B 片段保持刚性（无限质量），轨迹量全程有限且
能量守恒。

## 2. 理论与体系

体系与势：
- TEST 势 HARMONIC；A 单原子气体入射，B 为 4 原子表面。
- B 原子质量取无限大（W≈10³⁰）实现刚性约束。

表面几何：
- 表面斜胞由 B 片段前四个原子定义，BOXLX/BOXLY/SKEW 据此推出。
- 碰撞参数在斜胞内圆盘均匀抽取，入射速度方向由 SKEW 角决定。

## 3. 方法与流程

1. 读取输入并初始化随机数（ISEED 固定）。
2. 组装 NSURF=2 斜胞入射流程：fort.88 记录每条轨迹的瞄准点（RX0/RY0），
   A 原子按瞄准点与入射方向放置，B 原子固定于平衡构型。
3. 每轨迹传播 NS 步并输出相空间（fort.1001 起）。

## 4. 核心验证

见 `fig_long_trajectory.png`。

> 图注：A 原子 z(t) 自入射高度起步下降，全程数值有限。判定依据：
> fort.88 瞄准点全部有限；总能量 H 守恒（极差为机器精度量级）。
> HARMONIC 测试势下方格表面无近距排斥，A 长时程可穿过表面平面
>（测试势固有属性）；真实刚性表面散射应使用 RST 势。
