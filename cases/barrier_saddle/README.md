# 势垒鞍点起始（BARRIER 模式）— 势垒激发初始条件验证

> 运行：`cd cases/barrier_saddle && ../../venus_test.e`（NBAR=1 基线，输入 input_qct.txt）。

## 1. 目的

验证 `TASK=BARRIER`（NSELT=3，势垒激发模式）的核心语义：轨迹从指定驻点出发，
程序将简正模重排为采样模与反应坐标模，并把 EBAR 的能量精确注入反应坐标。

## 2. 理论与体系

体系为三原子共线 H₃ 的 LEPS 测试势（`TEST_PES = LEPS`）。驻点为共线对称驻点
（QZA_EQ 给出，原子 2 位于原点、沿 x 轴），为指标-2 驻点：Hessian 谱含二重简并
弯曲虚模（|ν| = 449.18 cm⁻¹）与两个实伸缩模（1225.26、1791.12 cm⁻¹）。

**模计数与重排**：NMA = 3N − (6 − NLINA) = 4 为采样模数，NMBAR = 3 为势垒模数，
IBARR = 1 为势垒模起始索引。重排后采样模集合 = {0.5134 cm⁻¹ 转动低频模式、
反对称伸缩、对称伸缩}，反应坐标模 = 弯曲虚模。

**流程**（与输出文件对应）：读入 QZA_EQ 在驻点处做力常数分析（`fort.77`）→
对角化得简正模与频率（`fort.26` 频谱块）→ 按 NMA/NMBAR/IBARR 重排（虚模移出
采样集合，成为反应坐标模）→ 采样模取量子数（`fort.9`）、反应坐标模按 NBAR 分支
赋动量 PBAR = √(2·C1·EBAR)，反应坐标能量 E_rc = PBAR²/(2·C1) = EBAR 恒等 →
BAREXC 注入 EBAR 后演化轨迹（`fort.8`、`fort.1001`–`1002`）并汇总（`fort.999`）。
