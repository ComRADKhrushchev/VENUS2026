# cau_tab PES 表文件格式（v2 通道直读，2026-10-01 裁决修订）

本文件是 `systems/inactive/cau_tab/` 容器的势能表格式规范。容器的 PES 唯一来源是
`TABLE_FILE` 指定的表文件；**手工调整表数据点即完成一次敏感性实验**（复制表文件 →
改点 → `TABLE_FILE = <副本名>` 重跑散射），装载回显会把每次运行所用表的形态写进
stdout 作为出处记录。

**v2 裁决（用户 2026-10-01）**：表携带**五个通道** E0 / h / U / J / VCP 直读直插，
不做四透热态加减（叠加各片插值误差与 C1 折痕，通道振荡）；GS 的 DFT 数据不参与
计算（仅参考），力学基底 = E0 通道。晶场劈裂 δcf 保持解析（h(1/2) = h ± δcf）。

## 文件结构

```
# cau_tab PES table v1
# <出处谱系/实验注记——鼓励填写，会随装载回显进入运行记录>
LATTICE 2.95
SHEET GS
SITE top 0.0000 0.0000
  0.5000   18.234
  0.7500   10.117
  ...
SITE bridge 1.4750 0.0000
  0.5000   21.552
  ...
SITE hollow 1.4750 0.8516
  ...
SHEET 1D
...
```

- 注释行以 `#` 开头，可出现在任何位置；空行自由。
- `LATTICE <a>`：横向周期 [Å]，全文件恰一行。必须与运行所用 POSCAR 晶格一致
  （容器不做交叉校验，装载回显提示——不一致时物理横向周期错，责任在制表侧）。
- `SHEET <名字>`：六块各恰一次，次序自由。名字固定为 `GS`、`1D`、`3P`、`mC`、`pC`、
  `VCP`（基态 / 四张透热态片 / 耦合片——Hubbard 组合链 J = E₁D−E₃P、
  U = E_mC−E₁D−E₃P+E_pC、h̃ = (E₁D−E_pC)−U、Vcp = E_VCP 的原料）。
- `SITE <标签> <x> <y>`：每片内 `top`、`bridge`、`hollow` 各恰一次，标签匹配不按
  次序。坐标为表面笛氏 [Å]（六角胞内），**跨片必须一致**（容差 1e-3 Å，装载器
  自检）。hollow 取 FCC 还是 HCP（或均值）由数据制备决定，在表头注记注明即可。
- 数据行：`z  E` 两列，z 为 C 相对表面锚原子的高度 [Å]，E 为该通道数值 [eV]。
  每位点至少 4 点，z 严格升序，行数自由（每位点硬上限 1024 点）。
- **能量列请写满有效位**（≥12 位，如 es24.16/f17.9 风格）：判据调参实测 9 位
  有效数字（es16.8）的舍入就足以把 FD 对拍放大成 1e-4 量级噪声；DFT 数据本身
  的物理噪声不受此影响，但转录时不要人为截断。

## 坐标与单位约定

- 全程 Å / eV，容器内零换算（换算只在 force_facade 边界，仓库立法）。
- z 的物理含义与 cau_peri 引擎一致：入射 C 相对锚 S 的高度。运行时求值高度经
  6 Å 冻结线 warp（[5,6] 平滑坡，≥6 Å 全部在 z_eff=6 求值）——表覆盖到 6 Å 即可
  服务的完整轨迹空间。
- 横向：三位点值经三系数傅里叶基（周期 = LATTICE）合成任意 (u,v)——与 cau_peri
  的 NN 路径同构。位点坐标本身只做一致性自检，插值按标签取值。

## 越界政策（装载器/求值器立法）

- z 低于位点首点：`fatal:` 中止，点名 sheet/site/请求 z/表最小 z。**不外推物理**——
  表覆盖不足由制表侧补数据解决。
- z 高于位点末点：末值保持 + 零梯度（渐近 hold，与 6 Å 冻结线裁决自洽）。

## 手工调整指南（敏感性实验工作流）

1. 基线表保持不动；`cp pes_table.txt exp_<注记>.txt`。
2. 在副本上改点：直接改某点的 E（局部抬升/压低势阱、垒）、插入新行（加密或造
   局部特征——行数自由）、删除行。注意保持 z 严格升序。
3. 运行目录 `input_qct.txt` 写 `TABLE_FILE = exp_<注记>.txt`，其余键与基线逐字
   相同（同 RNG 流、同初条件）。
4. 对比 fort.* / 记录列。stdout 的装载回显（文件名、位点数、z 区间）即本次
   实验的表出处。

## 数据密度要求与建议（实测标定，scripts/density_probe.f90）

**装载器硬规则**：每片 × 每位点 ≥4 点（Akima 下限）；z 严格升序；每位点 ≤1024 点；
六片 × 三位点齐全；z 覆盖必须包含**轨迹可及的最深转折点**（低于首点运行期 fatal，
不外推），上界到 6 Å 即可（冻结线以上数据不会被求值）。

**密度-精度实测**（恒等表、均匀网格、三站点最大离点误差）：

| 网格 dz | 壁区 [1.0,1.5] | 阱区 [1.5,3.0] | 尾区 [3.0,5.5] | J 通道 | 轨迹漂移* |
|---|---|---|---|---|---|
| 0.05 Å | 1.4e-1 eV | 2.3e-3 | 9.3e-5 | 1.5e-2 | −0.019 kcal |
| 0.10 Å | 8.5e-1 | 4.0e-2 | 8.9e-4 | 9.8e-2 | −0.019 |
| 0.20 Å | 6.0 | 2.8e-1 | 5.3e-3 | 4.6e-1 | −0.009 |
| 0.25 Å | 8.3 | 4.3e-1 | 1.5e-2 | 9.9e-1 | −0.041 |
| 0.50 Å | 2.4e1 | 1.9 | 3.8e-2 | 3.1 | −0.052（超阈） |

\* i1 口径：300 步 × 0.5 fs 无武装轨迹。误差按 ~dz³ 标度；壁区曲率（Morse 指数）
主导总误差——**均匀网格不经济，建议非均匀**（装载器原生支持任意升序非均匀网格）：
壁区 0.02–0.05 Å、阱区 0.05–0.10 Å、尾区（>3.5 Å）0.2–0.5 Å。总点数约为均匀
0.05 网格的三分之一而壁区精度更好。

**密度救不了的两件事**：① 横向分辨率被三位点傅里叶形式定死（top/bridge/hollow
三站点即满额，更多横向 DFT 点只会被弃用）；② DFT 数据自身噪声——Akima 直插把
噪声原样变成力的抖动，若数据噪声 ~1e-2 eV 量级，加密网格的边际收益为零，先做
数据侧平滑（见计划文档"后续候选"）。

**实验设计角度**：你要测试的局部特征在基线表中应被 ≥4–6 个点覆盖（跨特征宽度），
否则特征本身未被网格分辨；加行自由，上限 1024 点/位点。
