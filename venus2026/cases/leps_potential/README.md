# LEPS 势能面正确性验证

> 运行：`cd cases/leps_potential && ../../venus_test.e`（LEPS H₃ 等边极小起始
> 单轨迹，输入 input_qct.txt）。

## 1. 目的

验证 TEST 势 LEPS 分支（CGM 三原子形式）实现的正确性：以两张标准
三原子势能面切片的等值线拓扑与解析锚点判定，辅以极小起始单轨迹的
能量闭合。

## 2. 理论与体系

LEPS 势（`src_TEST/test_potentials.f90` 的 `leps_vg`）：
- V = ½ΣQ_p − ½√Σ(A_p−Q_p)²，三个原子对支路 Q_p/A_p 由 Morse 型
  参数化（De=4.746 eV、re=1.401 Å、a=1.028 Å⁻¹、Sato Δ=0.164）。
- 体系为 H₃（NATOMS=3，全为 1.008 u），初始构型取等边极小
 （QZA_EQ 边长 1.759910 Å，同 boltzmann_vib）。

解析锚点（判定依据的来源）：
- 等边极小：r=1.760 Å，V=−6.381 eV——与程序 VZERO 输出（fort.666
  −147.147 kcal/mol）五位一致，是解析式与程序实现的直接对账点。
- 共线对称路径势垒：11.8 kcal/mol（相对 H₂+H 渐近 −4.05 eV）。
- H₂+H 渐近谷：−4.05 eV；LEPS 内有效 H₂ 键长 re≈1.50 Å。

## 3. 方法与流程

1. plot_fig.py 按源码同式解析式计算 LEPS 两个标准切片的网格
 （与 `leps_vg` 逐式对应），绘制 fig_leps_surfaces.png：
 (a) 共线 H+H₂（r₁₃=r₁₂+r₂₃，反应坐标面）；(b) 固定 r₁₃ 过等边
   极小的切片。叠加解析锚点。
2. 运行等边极小起始单轨迹（fort.1001），轨迹能量与极小深度对照。

## 4. 核心验证

见 `fig_leps_surfaces.png`。

> 图注：(a) 共线 H+H₂ 面——反应谷（白三角，−4.05 eV）—鞍点—反应谷的
> 对称拓扑，红虚线为对称路径（垒 11.8 kcal/mol），红星为共线对称极小；
> (b) 固定 r₁₃=1.7599 Å 切片——两轴 Morse 壁 + 中心等边阱（红星，
> −6.381 eV）。判定依据：极小深度与程序 VZERO 输出（fort.666
> −147.147 kcal/mol）五位一致；垒高、渐近值锚点命中；等边极小起始
> 轨迹 E0=−6.381 eV 与解析一致。
